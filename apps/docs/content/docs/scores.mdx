# Scores

A score is a judgment attached to something you recorded: a grade from an
automated judge, a rating from a reviewer, or a thumbs-up from a user. Scores are
the measurable output of evaluation.

## Anatomy of a score

| Field | Description |
|-------|-------------|
| `name` | The metric, e.g. `helpfulness`, `tone`. **Required** |
| `value` | The numeric value — also used for boolean `0` / `1` |
| `stringValue` | The category label, for a categorical score |
| `dataType` | `NUMERIC`, `CATEGORICAL`, or `BOOLEAN` |
| `traceId` / `runName` / `datasetName` / `datasetItemId` | What it is attached to |
| `comment` | Optional note, up to 2,000 characters |

## Write one

```bash
curl -X POST https://api.hanzo.ai/v1/evals/scores \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "helpfulness",
    "dataType": "NUMERIC",
    "value": 4,
    "traceId": "tr_71ab",
    "comment": "Answered, but buried the actual step."
  }'
```

## Read them

```bash
curl "https://api.hanzo.ai/v1/evals/scores?name=helpfulness&limit=100" \
  -H "Authorization: Bearer $HANZO_API_KEY"
```

Filter by `name`, `runName`, `traceId`, and `limit`.

## Keeping them consistent

Declare the metric's shape once as a [rubric](/docs/score-configs) and every
later write is checked against it: a `NUMERIC` value must fall inside the
declared bounds, a `BOOLEAN` must be exactly `0` or `1`, and a `CATEGORICAL`
`stringValue` must be one of the declared categories. A rubric also **overrides**
whatever `dataType` a writer claims, so one metric cannot end up with two shapes.

## Where scores come from

- **An [eval run](/docs/evals)** — the LLM judge scores every item and writes the
  result, along with a trace per item.
- **Your application** — user feedback, written through the same endpoint.
- **A reviewer** — a person grading recorded output by hand.

Scores attached to spans through the observability plane are read separately at
`GET /v1/o11y/llm/scores`, alongside [observations](/docs/observations).
