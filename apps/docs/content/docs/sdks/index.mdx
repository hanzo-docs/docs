# Hanzo SDKs

**Hanzo AI — one API for every model, one SDK for every language.** Talk to the
Open AI Cloud from the language you already work in. Every SDK is generated from
the same OpenAPI 3.1 spec and shares one credential.

## Two libraries per language

Each language has two first-class lines — install the one that fits the job, or
both:

<Cards>
  <Card title="Cloud SDK">
    The full, generated client for the **entire** Open AI Cloud (`/v1/*`): AI,
    agents, compute, data, network, security, platform, observe, web3, apps.
    Idiomatic and typed for its ecosystem. Real code lives in `hanzo-<lang>/sdk`.
  </Card>
  <Card title="AI / Agents lib">
    The hand-crafted, AI-first library — models, agents, tools, memory, MCP, and
    inference. The flagship is Python (`pip install hanzo`); Node ships
    `@hanzo/ai`.
  </Card>
</Cards>

## Quick start

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Every client follows the same shape — construct with your key, call a `/v1`
resource:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## One key, one base URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Get your key at [console.hanzo.ai](https://console.hanzo.ai).
