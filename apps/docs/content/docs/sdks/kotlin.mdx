# Kotlin

Coroutine-native, on OkHttp and Gson — the same HTTP and JSON stack the
[Java](/docs/sdks/java) client uses, so a JVM project pulling both pulls one
stack. Generated from the API's own document.

## Install

```kotlin
// build.gradle.kts
dependencies {
    implementation("ai.hanzo:sdk:8.0.0")
}
```

<Callout title="Maven Central publication is in progress">
Until `ai.hanzo:sdk` lands there, consume the repository through JitPack: add
`maven("https://jitpack.io")` to `repositories`, then
`implementation("com.github.hanzo-kt:sdk:v8.0.0")`.
</Callout>

## The shape

Authenticate once on `ApiClient`, then call the capability's class:

```kotlin
import ai.hanzo.sdk.apis.AgentsApi
import ai.hanzo.sdk.infrastructure.ApiClient
import kotlinx.coroutines.runBlocking

fun main() = runBlocking {
    // Base URL defaults to https://api.hanzo.ai.
    ApiClient.accessToken = System.getenv("HANZO_API_KEY")

    val agents = AgentsApi().chatGetAgents()
    println(agents)
}
```

Every capability is an `*Api` class — `AiApi`, `AgentsApi`, `BillingApi`, and
the rest — and every method is a suspending function. The class and the method
both come from the document, so the [reference](/docs/openapi) is the index.
`accessToken` takes an IAM access token or a Hanzo API key; see
[Authentication](/docs/api-keys).
