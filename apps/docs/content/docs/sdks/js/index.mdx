# Build on Hanzo with JavaScript

`hanzo.js` is the umbrella SDK for building on Hanzo from JavaScript or TypeScript. One install gives you the whole client surface, namespaced — or install the individual packages for a smaller footprint. Every package speaks the one Hanzo API at **`https://api.hanzo.ai/v1`**, authenticated with a Hanzo IAM access token or a publishable key, and the AI clients default to the **`enso`** model.

<Callout title="No /api/ prefix, ever">
Hanzo APIs live at `api.hanzo.ai/v1/...` — the clients join paths against that base and never insert an `/api/` segment. `enso` is the default model everywhere an AI call is made.
</Callout>

## Install the umbrella

```bash tab="npm"
npm install hanzo.js
```

```bash tab="pnpm"
pnpm add hanzo.js
```

```bash tab="bun"
bun add hanzo.js
```

`hanzo.js` re-exports five packages verbatim as namespaces:

```ts
import { ai, iam, commerce, checkout, track } from 'hanzo.js'

// The AI client — defaults to https://api.hanzo.ai, model `enso`.
const client = ai.createAiClient({ token: process.env.HANZO_TOKEN })

const res = await client.chat.completions.create({
  model: 'enso',
  messages: [{ role: 'user', content: 'Explain MoE routing in one sentence.' }],
})
console.log(res.choices[0].message.content)
```

The umbrella bundles [`@hanzo/ai`](/docs/sdks/js/ai), [`@hanzo/iam`](/docs/sdks/iam), [`commerce.js`](/docs/sdks/js/commerce), [`checkout.js`](/docs/sdks/js/checkout), and [`track.js`](/docs/sdks/js/track). The UI surfaces (`@hanzo/chat`, `@hanzo/agent`, `shop.js`, `coin.js`, `dash.js`, `@hanzo/css`) are **separate installs** — pull them in only where you render UI.

## Authentication

Every Hanzo API call carries one of two credentials:

| Credential | Looks like | Where it comes from | Use it for |
| --- | --- | --- | --- |
| **Publishable key** | `pk_live_…` / `pk_test_…` | Hanzo IAM / [console](https://console.hanzo.ai) | Browser widgets — checkout, forms, embedded capture. Safe to ship in client code; restricted scope. |
| **IAM access token** | a bearer JWT | [`@hanzo/iam`](/docs/sdks/iam) after a user signs in (OIDC/PKCE) | Authenticated, user-scoped calls — AI, billing, wallet, account. |

The AI and commerce clients accept either a static `token` or a lazy `getToken()` so rotating tokens are handled for you. See [Quickstart / Embed](/docs/sdks/js/quickstart) for the drop-in, publishable-key story, and [Authentication](/docs/authentication) for how sessions work across Hanzo.
