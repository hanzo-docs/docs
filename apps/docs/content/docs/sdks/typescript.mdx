# TypeScript SDK

Two first-class packages, both generally available on npm. Runs on Node, Deno,
Bun, and the browser.

<Cards>
  <Card title="@hanzo/ai — AI lib">
    `npm i @hanzo/ai`. The AI-first library — models, agents, tools, streaming.
    Source: [hanzo-js/ai](https://github.com/hanzo-js).
  </Card>
  <Card title="@hanzo/sdk — Cloud SDK">
    `npm i @hanzo/sdk`. The full, generated client for the entire Open AI Cloud
    (`/v1/*`). OpenAI-compatible surface. Source: [hanzo-js/sdk](https://github.com/hanzo-js).
  </Card>
</Cards>

## Install

```bash tab="AI lib"
npm i @hanzo/ai
```

```bash tab="Cloud SDK"
npm i @hanzo/sdk
```

```bash tab="pnpm"
pnpm add @hanzo/sdk
```

```bash tab="bun"
bun add @hanzo/sdk
```

Set your key once:

```bash
export HANZO_API_KEY="hk-..."   # from console.hanzo.ai
```

## Quick start — Cloud SDK

```typescript
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY });

const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Explain quantum computing' }],
});

console.log(response.choices[0].message.content);
```

### Streaming

```typescript
const stream = await client.chat.completions.create({
  model: 'zen5-coder',
  messages: [{ role: 'user', content: 'Write a haiku about AI' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}
```

## Quick start — AI lib

```typescript
import { Agent } from '@hanzo/ai';

const agent = new Agent({ model: 'zen5', tools: ['search', 'shell'] });
const result = await agent.run('Summarize the latest release notes.');
console.log(result.output);
```

<Callout title="Base URL">
Every service is reachable at `https://api.hanzo.ai/v1`. The client defaults
there; override with `baseURL` for a self-hosted gateway.
</Callout>

## Configuration

```typescript
const client = new Hanzo({
  apiKey: process.env.HANZO_API_KEY,
  baseURL: 'https://api.hanzo.ai/v1', // default
  timeout: 60_000,
  maxRetries: 2,
});
```
