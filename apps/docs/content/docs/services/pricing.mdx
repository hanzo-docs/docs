# Pricing API

> **API reference** · [Hanzo Pricing API →](/docs/openapi/pricing) — every endpoint, generated from the OpenAPI spec.

The Hanzo Pricing API provides real-time pricing for the entire Hanzo platform — AI models, cloud VMs, GPU compute, tools, and subscription plans.

**Base URL:** `https://pricing.hanzo.ai`

## Key Endpoints

| Endpoint | Description |
|----------|-------------|
| `GET /v1/models` | Per-model rates — the live catalogue and its pricing |
| `GET /v1/plans` | Subscription plans (Developer, Pro, Team, Enterprise) |
| `GET /v1/cloud` | Cloud VM plans, regions, and storage |
| `GET /v1/gpu` | GPU tier pricing (H100) |
| `GET /v1/tools` | Tool pricing (Web Search, Code Interpreter, etc.) |

## Features

- **Model rates** — the `enso` and Zen families, and the outside models we carry, each with its input and output price per 1M tokens
- **11 cloud VM plans** — from $5/mo (Starter) to $3,999/mo (Ultra)
- **Zero egress fees** on all plans
- **6-hour sync** — rates for carried models refresh from their upstreams automatically
- **Revenue sharing** — earn up to 20% on idle compute resale

`GET /v1/models` is the source of truth for what a model costs today. Each entry
carries its `id`, `owned_by`, `premium` flag and `pricing`.

## Authentication

Most endpoints are public (no auth required). The `/v1/sync` endpoint requires a Bearer token.

## Rate Limits

No rate limits on pricing API reads. Data is cached in-memory with 6-hour TTL.
