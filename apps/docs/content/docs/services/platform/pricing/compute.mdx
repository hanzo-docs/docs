There are two ways Platform gets you a machine, and they bill differently.

| | Who bills | Rate card |
|---|---|---|
| **Hanzo-hosted instances** | Hanzo | `GET https://pricing.hanzo.ai/v1/cloud` (CPU), `GET https://pricing.hanzo.ai/v1/gpu` (GPU) |
| **Your own cloud account** via [Visor](/docs/services/platform/virtual-machines) | AWS / DigitalOcean / Hetzner, directly | Your provider's published rate |

Visor launches instances on accounts you connect with **your own API credentials**, so
for that path Hanzo is not in the transaction at all.

<Callout title="Read the rate, do not copy it">
Instance tiers, sizes and prices change. Fetch them:

```bash
curl https://pricing.hanzo.ai/v1/cloud   # CPU tiers, regions, block storage
curl https://pricing.hanzo.ai/v1/gpu     # GPU tiers, per-hour rates
```

A number written into a page is a snapshot; the endpoint is the contract. The billed
rate is always what the API returns at provision time.
</Callout>

## GPUs

Accelerator families, node sizes, clusters and pools are documented in
[GPUs](/docs/gpus). Sizes are named for what they hold — `gpu-h100x1-80gb` is one
H100, `gpu-h100x4-320gb` is four.

## What a subscription covers

Your Hanzo subscription and its included AI allowance are separate from compute — see
[Plans](/docs/services/platform/pricing/plans) and [Billing](/docs/billing).
