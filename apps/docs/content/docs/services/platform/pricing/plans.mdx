Hanzo Platform itself is free and self-hostable. What carries a subscription is your
Hanzo account, and every surface that shows a price — [hanzo.ai/pricing](https://hanzo.ai/pricing),
[hanzo.app/pricing](https://hanzo.app/pricing), the console, this page — reads the
same catalog:

```bash
curl https://api.hanzo.ai/v1/billing/plans
```

<Callout title="The API is the source of truth">
The table below is the catalog as published. If a number here disagrees with
`GET /v1/billing/plans`, the API is right and this page is stale — open an issue.
Nothing prices a plan from a hard-coded table.
</Callout>

## Personal

| Plan | Monthly | Billed annually | What it is |
|------|---------|-----------------|------------|
| **Go** | $9 | $8.25/mo | Omnichannel agent hosting and the Hanzo desktop app |
| **Dev** | $19 | $16.50/mo | Terminal-native pair programming in your own repo shell |
| **Pro** | $49 | $41.50/mo | Multi-agent orchestration, background review, max reasoning depth |
| **Max** | $99 | $83.25/mo | Enso orchestration, unlimited managed agents, shared workspaces |

## Team

| Plan | Per seat / month | Billed annually | Minimum |
|------|------------------|-----------------|---------|
| **Team** | $25 | $20/seat/mo | 2 seats |

Team adds org workspaces with shared history and projects, SSO via
[Hanzo IAM](/docs/services/iam), one unified bill, and centralized KMS-backed
credentials.

## Enterprise

**Enterprise** is contact-sales: dedicated compute, on-premise or air-gapped
deployment, custom SLA, custom model training and hosting, SOC 2 support.

## DNS

[Hanzo DNS](/docs/services/dns) prices separately: **Free** $0, **Pro** $5/mo,
**Enterprise** $25/mo.

## What a subscription does not cover

- **Metered usage above the included allowance** — priced per model by
  `GET /v1/pricing/models` and billed through [Commerce](/docs/commerce).
- **Infrastructure you run yourself.** Platform deploys onto *your* clusters and
  *your* cloud accounts; see [Compute](/docs/services/platform/pricing/compute) and
  [Storage](/docs/services/platform/pricing/storage).
