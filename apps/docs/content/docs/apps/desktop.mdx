# Hanzo Desktop

**Hanzo Desktop is the Hanzo app on your computer**: Chat, Dev, Studio and your
agents in one window, and a global hotkey that brings Hanzo to whatever you are
doing. Agents can run against models on your own machine or on Hanzo Cloud. If
you are not sure which Hanzo to install, install this one.

## Install

1. Open **[hanzo.ai/download](https://hanzo.ai/download)**. The button offers the
   latest build for your system: a `.dmg` for macOS (Apple Silicon and Intel), a
   setup `.exe` for Windows, an AppImage or `.deb` for Linux (x86_64 and arm64).
2. Install it like any other app, and open it.
3. Choose **Sign in with Hanzo**. Your browser opens the Hanzo sign-in page (create
   an account there if you have none) and hands you back to the app. Or choose
   **Continue without login** to run on a local model with no account.

No terminal, no `curl`, `npm` or `brew`. Every build and its checksums are on
[GitHub](https://github.com/hanzoai/desktop/releases/latest).

Nothing to install at all: the same app runs in your browser at
[hanzo.app](https://hanzo.app).

## Local Cloud & Custom API Endpoint

To point Hanzo Desktop at a local Cloud stack (`make up` in `hanzo-inc/universe` on `http://127.0.0.1:8000`), Devnet (`https://api-dev.hanzo.ai`), or any custom endpoint:

1. Open **Settings → Environments & Machines → Cloud API Endpoint** (or **Settings → Advanced → Local services**).
2. Select **`Local Cloud (make up)`** (`http://127.0.0.1:8000`), click **Test** to verify `/v1/health`, and click **Apply & Reload** (or launch from the terminal with `HANZO_CLOUD_API=http://127.0.0.1:8000 hanzo-desktop`).

## Build & Install from Source

Contributors building Hanzo Desktop from the unified `hanzo-inc/app` monorepo (`desktop/`):

```bash
make deps       # installs OS build deps (Ubuntu/Debian/Fedora/Arch/WSL2, macOS, Windows notes) + pnpm workspace
make desktop    # builds desktop/src-tauri/target/release/hanzo-desktop (or macOS Hanzo.app)
make install    # installs ~/.local/bin/hanzo-desktop + Dock launcher (or /Applications/Hanzo.app) and launches
make linux-pkg  # packages distributable .deb and .rpm bundles
```

## Desktop or the CLI?

The [Hanzo CLI](/docs/cli) (`hanzo`) is for developers: it runs in a terminal,
starts [Hanzo Dev](/docs/dev) (the coding agent) with `hanzo dev`, and drives your
account and the cloud from scripts. You do not need it to use Hanzo Desktop.

## Claude Desktop

Add Hanzo's tools to Anthropic's Claude Desktop with the
[Hanzo MCP server](/docs/mcp#client-setup): paste its `mcpServers` entry into
Claude Desktop's config (**Settings → Developer → Edit Config**) and restart.

> **One identity, everywhere.** Sign in with Hanzo ([IAM](/docs/openapi/iam)
> OAuth) or paste an `sk-` [API key](/docs/api-keys). The same account carries
> your models, tools and usage across every surface.
