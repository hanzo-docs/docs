# Desktop apps

Two apps, two jobs. **Hanzo Agents** runs on your machine and builds agents that
can use models running locally or in the cloud. **Hanzo Menubar** is the
one-keystroke assistant.

## Hanzo Agents

Build agents that work together, handle payments, and automate workflows —
against models running **on your own machine** or in the cloud, for macOS
(Apple Silicon), Windows and Linux.

Not published: its source and its builds are not public, so there is nothing to
install.

## Hanzo Menubar

A menubar / system-tray app with a global hotkey — **Cmd/Ctrl + Shift + Space** —
for chat, quick actions, and agents over the same account you use everywhere else.

Not published: its builds are not public, so there is nothing to install.

## Claude Desktop

Add Hanzo's tools to Anthropic's Claude Desktop with the
[Hanzo MCP server](/docs/mcp#client-setup): paste its `mcpServers` entry into
Claude Desktop's config (**Settings → Developer → Edit Config**) and restart.

> **One identity, everywhere.** Sign in with Hanzo ([IAM](/docs/openapi/iam)
> OAuth) or paste an `sk-` [API key](/docs/api-keys). The same account carries
> your models, tools and usage across every surface.
