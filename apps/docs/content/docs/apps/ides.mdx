# IDEs & editors

Chat about a file, refactor a selection, run an agent across the repo — with the same models and tools you get everywhere else.

## Connect your editor

Two connections, and neither needs a download from us:

- **Tools** — add the [Hanzo MCP server](/docs/mcp#client-setup) to any editor that speaks MCP (Cursor, Windsurf, Antigravity, VS Code agent mode, JetBrains AI Assistant). One entry gives the editor every Hanzo tool.
- **Models** — in an editor that takes a custom OpenAI-compatible provider, set the base URL to `https://api.hanzo.ai/v1` and paste an `sk-` [API key](/docs/api-keys).

The native Hanzo extension for these editors is not published: it is on no marketplace (VS Code Marketplace, Open VSX, JetBrains Marketplace, PyPI) and its builds are not public.

> **One identity, everywhere.** Sign in with Hanzo ([IAM](/docs/openapi/iam) OAuth) or paste an `sk-` [API key](/docs/api-keys). The same credential works in every Hanzo surface — see [Integrations & Extensions](/docs/apps).
