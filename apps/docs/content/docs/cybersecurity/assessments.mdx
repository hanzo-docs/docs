**Point-in-time annual audits decay the day after the PDF is signed.** Hanzo exposes continuous security posture, risk scoring, and framework control evidence through live `/v1/` endpoints so CI pipelines and customer trust portals read the same source of truth.

## Continuous posture assessment across four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
# Org scan history and active findings
hanzo security scans list
hanzo security findings list

# Compliance status & trust center controls
hanzo compliance status
hanzo trust coverage --framework soc2
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, SecurityApi, TrustApi, ComplianceApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [scans, coverage, compliance] = await Promise.all([
  new SecurityApi(cfg).getSecurityScans(),
  new TrustApi(cfg).getTrustCoverageByFramework('soc2'),
  new ComplianceApi(cfg).getComplianceStatus(),
]);
console.log({ scans: scans.data, coverage: coverage.data, compliance: compliance.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import SecurityApi, TrustApi, ComplianceApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(SecurityApi(client).get_security_scans())
print(TrustApi(client).get_trust_coverage_by_framework("soc2"))
print(ComplianceApi(client).get_compliance_status())
```
</Tab>
</Tabs>

<Tab value="HTTP">
```bash
# 1. Recent security scans
curl -s https://api.hanzo.ai/v1/security/scans \
  -H "Authorization: Bearer $HANZO_API_KEY" | jq '.'

# 2. Trust center framework coverage (e.g. soc2)
curl -s https://api.hanzo.ai/v1/trust/coverage/soc2 \
  -H "Authorization: Bearer $HANZO_API_KEY" | jq '.'

# 3. Real-time risk score evaluation
curl -s -X POST https://api.hanzo.ai/v1/risk/score \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"subject":"deploy_prod","features":{"new_secret_findings":0,"unverified_images":1}}' | jq '.'
```

## CI release gate pattern

Wire `POST /v1/security/scans` into every pull request:
- Fail the build on any high-severity secret finding (`rule`, `path`, `line`, `fingerprint`).
- Attach `GET /v1/sbom/{ref}` output to your release attestation.
- Upload passing control evidence to `POST /v1/trust/evidence` so framework coverage stays current automatically.
