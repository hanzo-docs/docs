**Kai decides; it does not write.** You send a state and named questions:
which label, does a statement hold, which level. Kai returns a probability for
every option, and your code acts on the answers. `usage.output_tokens` is
always 0.

```bash
curl -sS https://api.hanzo.ai/v1/decisions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kai",
    "state": {"ticket": "I was charged twice for my March invoice. Please refund the duplicate today."},
    "questions": {
      "team":    {"type": "choice", "instructions": "Which team should handle `ticket`?",
                  "criteria": {"billing": "charges, invoices and refunds",
                               "technical": "bugs and outages",
                               "account": "logins and profiles"}},
      "urgency": {"type": "score", "instructions": "How urgent is `ticket`?",
                  "criteria": ["later", "this week", "today", "now"]}
    }
  }' | jq 'del(.latency_ms)'
```

`team` is settled. `urgency` is not: no level holds more than 0.32 and its
`confidence` is 0.09, although the ticket says "today". Act on the first,
send the second to a person or ask a sharper question. That split is the whole
programming model: [Confidence](/docs/kai/confidence) says how to set the line.

## Call it

| From | Install | Call |
|---|---|---|
| HTTP | nothing | `POST https://api.hanzo.ai/v1/decisions` ([reference](/docs/decisions)) |
| Python | `pip install hanzo-kai` | `Kai().decide(state=..., questions=...)` ([SDK](/docs/kai/sdk/python)) |
| TypeScript | `npm i @hanzo/kai` | `new Kai().decide({ state, questions })` ([SDK](/docs/kai/sdk/typescript)) |
| MCP | `@hanzo/mcp` | `kai_decide`, `kai_choice`, `kai_score`, `kai_noul` ([agents](/docs/kai/agents)) |
| Agent skill | `npx skills add https://hanzoskills.com/kai.md` | ([agents](/docs/kai/agents)) |

Every call takes a Hanzo key ([API keys](/docs/api-keys)) and is billed to the
key's org at \$0.021 per million input tokens; output is free.

## Against Jev

- **Price**: 50% lower input-token list price (\$0.021 vs \$0.042 per 1M).
  Output is free on both.
- **Accuracy**: on the frozen decision harness, Kai (checkpoint a7) is more
  accurate than Jev on 11 of 12 suites; Jev leads jailbreak detection, 0.940
  to 0.920 ([results](https://github.com/hanzoai/benchmarks/tree/c61361fedc5882b0d83b2f5d5a6a35c56ffeb3c3/decision/results/kai-a7),
  [suite by suite](/docs/models/kai#results)).
- **Wire**: the same question types and answer shapes, so a Jev request
  becomes a Kai request when the base URL, the key and `model` change.
