**Text copied out of a terminal or a PDF keeps its words and loses its
structure.** The script flattens one of our READMEs, then asks two questions
of the result: does each line continue the block before it, and what kind of
block is each one. The original README is the answer key.

## The idea

The README is [Hanzo Base's](https://github.com/hanzoai/base/blob/4506925bff6d89aafbf7433bc0abec0d6131865e/README.md),
pinned to a commit. Flattening drops every marker (`#`, `-`, code fences),
every blank line, the table and the image, and wraps the prose at 64
characters, the way a terminal copy does. What is left is a list of lines, each still tagged in
the script with the block it came from.

Rebuilding is two decisions:

- **join or break**, per boundary between two lines: does the second continue
  the block the first is in? One choice per boundary, the two lines in its
  instructions, fifty boundaries to a call.
- **what kind**, per block of the original: heading, paragraph, list item or
  code. One choice per block, all in one call, so a wrong join cannot spoil
  the kind.

Beside Kai, one rule in code: a line that nearly fills the wrap width was
wrapped, so it joins the next.

## What the numbers say

- **Kai joins nearly every line.** It marked 3 of the 22 real breaks and added
  4 where there is none. Its 56 right of 79 is no better than answering "same"
  at every boundary, which scores 57.
- **Kai calls every block code.** It got 6 of 23 right, the six code blocks;
  every heading, paragraph and list item was labelled code as well.
- **The width rule finds the paragraphs.** A line near the 64-character wrap
  width was wrapped, so it joins the next: that marked 19 of the 22 breaks. Of
  its 36 false breaks, 34 are lines inside code blocks, which are short by
  nature, and two are prose lines cut short before a long token.

On this checkpoint Kai reads no layout. Rebuild structure in code.

## Adapt it

- Join prose by the wrap width, as the rule here does, and treat a run of short
  lines as one block rather than as many.
- Tell code from prose by its characters, in code, and check the rule against
  a document whose structure you know, as this script checks against the
  original README.
- Keep this script as the test for the next checkpoint: it prints the same
  counts, and a model that reads layout will move them.
