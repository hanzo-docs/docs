## Query Parameters

The deployment flow accepts `https://hanzo.app/deploy`, `https://hanzo.app/new`, and `https://hanzo.app/new/clone` interchangeably — existing Vercel Deploy Button links work by swapping the host to `hanzo.app`.

| Parameter | Required | Description |
| --- | --- | --- |
| `repository-url` | Yes | Public Git repository URL (supports `/tree/<branch>/<subdir>` paths for monorepos). |
| `project-name` | No | Default project name pre-filled in the deployment form. |
| `root-directory` | No | Subdirectory containing the app to build inside a monorepo. |
| `env` | No | Comma-separated list of required environment variable names (e.g. `HANZO_API_KEY,DATABASE_URL`). |
| `envDescription` | No | Helper text explaining where to obtain the required environment variables. |
| `envLink` | No | URL to documentation explaining how to configure the environment variables. |
| `build-command` | No | Override the auto-detected framework build command. |
| `output-directory` | No | Override the auto-detected build output directory. |
| `install-command` | No | Override the auto-detected package install command. |
| `via` | No | OSS maintainer handle or wallet ID to receive 20% referral attribution. |

For **Ask** and **Edit** buttons, use `https://hanzo.app/dev/open` with:

| Parameter | Description |
| --- | --- |
| `repo` | GitHub `owner/repo` slug or full repository URL. |
| `action` | `ask` (codebase Q&A), `edit` (interactive coding agent), or `deploy` (opens the deploy flow). |
| `branch` | Optional branch name to inspect or check out. |
| `prompt` | Optional initial instruction pre-loaded into Hanzo Dev. |
| `via` | Optional OSS maintainer handle for 20% contributor attribution. |

## Earn 20% OSS Contributor Rewards

Append `&via=<your-handle>` to any **Deploy**, **Ask**, or **Edit** badge in your repository README:

1. Visitors click your badge and launch a deployment or Hanzo Dev session with your repo pre-loaded.
2. Hanzo attributes their session and deployment usage to your `via` handle.
3. Connect your payout wallet in [Hanzo App Settings → Referrals](https://hanzo.app/settings/referrals) to receive up to **20% of AI compute and deployment revenue** generated from your open-source projects.

See the [Referrals documentation](/docs/referrals) for payout schedules and attribution rules.
