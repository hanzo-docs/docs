**No floating tags in production.** Every dataset, LoRA adapter, merged checkpoint, and Kai capability artifact on Hanzo is keyed by the SHA-256 digest of its bytes and encrypted under your org's KMS prefix.

## Artifact & serving lifecycle

1. **Store**: Uploads and executor outputs register on `/v1/train/artifacts` (`checkpoint`, `capability`, `lora`, `basis`, or `merged`) with SHA-256 verification enforced by S3 on PUT.
2. **Evaluate**: Held-out metrics attach to the job (`GET /v1/train/jobs/{id}/metrics`) or capability version (`GET /v1/capabilities/{name}`).
3. **Publish**: `POST /v1/train/jobs/{id}/publish`, `POST /v1/ai/finetune/deploy`, or `POST /v1/capabilities/{name}/publish` binds a named route to that exact digest.
4. **Serve & verify**: Responses report exact serving provenance (`routing.checkpoint`, `routing.sha256`, `routing.calibration`, `X-Hanzo-Served`).
5. **Roll back or retire**: Roll back to the prior digest (`POST /v1/capabilities/{name}/rollback`) or remove artifacts (`DELETE /v1/train/artifacts/{sha256}`).

## Inspect artifacts & published models

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
# List org-private training artifacts (datasets, adapters, checkpoints)
hanzo train artifacts list

# Inspect a specific artifact and obtain a 10-minute presigned download URL
hanzo train artifacts get "$SHA256"

# List live serving models visible to your org
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, TrainApi, AiApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const artifacts = await new TrainApi(cfg).getTrainArtifacts();
const models = await new AiApi(cfg).getModels();
console.log({ artifacts: artifacts.data, models: models.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import TrainApi, AiApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(TrainApi(client).get_train_artifacts())
print(AiApi(client).get_models())
```

## Serving custom ML models (`/v1/ml/models`)

Non-LLM tabular, ranking, and risk models publish to `/v1/ml/models` and serve low-latency inference at `POST /v1/ml/models/{name}/predict` under the same tenant IAM and billing ledger.
