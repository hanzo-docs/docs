Every model on Hanzo — **Enso** adaptive tiers, **Zen 6** open weights, and 500+ frontier models across OpenAI, Anthropic, Google Gemini, xAI Grok, Meta Llama, Qwen, DeepSeek, and Mistral — speaks one OpenAI-compatible `/v1/chat/completions` contract, online at `https://api.hanzo.ai/v1` or offline via `hanzo engine`.

## Routing Tiers & Open Weights at a Glance

| Model ID | Behavior | Ideal Workload |
| --- | --- | --- |
| `enso-auto` / `auto` | Starts on Flash; escalates to Pro/Max/Ultra only when Kai judges prompt complexity warrants it | Default production traffic & multi-turn agents |
| `enso-flash` · `enso-pro` · `enso-max` · `enso-ultra` | Explicit capability tiers with automatic cross-provider failover and prompt caching | SLA-bound production services |
| `zen6` · `zen6-coder` | 27B Apache-2.0 open-weight multimodal & agentic coding model (up to 1M context) | Code generation, tool calling, sovereign deployments |
| `zen6-flash` | 5.95 GB ternary weights running natively on Apple Silicon Metal or single GPU | Sub-second local/offline inference |

## 2. Streaming SSE & Structured JSON Schema Outputs

Enforce strict JSON Schema conformance for downstream pipelines and stream tokens over Server-Sent Events (`stream: true`):

```bash
curl -N -X POST https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen6",
    "response_format": {
      "type": "json_schema",
      "json_schema": {
        "name": "release_risk",
        "strict": true,
        "schema": {
          "type": "object",
          "properties": {
            "summary": { "type": "string" },
            "breakingChanges": { "type": "boolean" },
            "rollbackPlan": { "type": "string" }
          },
          "required": ["summary", "breakingChanges", "rollbackPlan"],
          "additionalProperties": false
        }
      }
    },
    "messages": [{ "role": "user", "content": "Audit dropping column legacy_token from users." }]
  }'
```

## 3. Offline & Air-Gapped Local Inference (`hanzo engine`)

Pull ternary `zen6-flash` weights once and serve the exact same `/v1/chat/completions` contract locally on Metal, CUDA, or CPU with zero external network egress:

```bash
# Download open-weight Zen 6 Flash locally
hanzo pull zenlm/zen6-flash

# Start Hanzo Engine (`hanzoai/engine`) on localhost:8080
hanzo engine serve --model zenlm/zen6-flash --port 8080

# Point your existing SDK or CLI at localhost — zero code changes
HANZO_BASE_URL=http://localhost:8080 curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"zen6-flash","messages":[{"role":"user","content":"Write a lock-free ring buffer in Rust."}]}'
```
