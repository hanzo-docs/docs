**Catch leaked keys before they land in git history or model weights.** `POST /v1/security/scans` runs Hanzo's rule engine over any file batch and returns structured, masked findings with line numbers and stable fingerprints.

## Architecture & contract

Findings store only masked previews and fingerprints — never raw secret material — scoped strictly to your org. Pair with CI pre-commit hooks and dataset upload pipelines.

**Primary endpoint:** `POST /v1/security/scans` · **Status:** `shipped` · **Level:** `practitioner`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo security rules
hanzo security scans create --data '{"files":[{"path":"deploy.sh","content":"export DATABASE_URL=postgres://app@db.internal/prod"}]}'
hanzo security findings list
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, SecurityApi } from 'hanzoai';

const sec = new SecurityApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data: scan } = await sec.postSecurityScans({
  files: [{ path: 'deploy.sh', content: 'export DATABASE_URL=postgres://app@db.internal/prod' }],
});
console.log(scan);
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import SecurityApi

api = SecurityApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
print(api.post_security_scans({"files": [{"path": "deploy.sh", "content": "export DATABASE_URL=postgres://app@db.internal/prod"}]}))
```

## Verify the outcome

- Run a scan against a clean file (expect `0` findings) and verify `GET /v1/security/scans/{id}` returns full scan metadata.

## Production guardrails

- Whenever a real credential triggers a finding, rotate it immediately in Hanzo KMS (`/v1/kms/secrets`) — deleting the commit alone is never sufficient.
