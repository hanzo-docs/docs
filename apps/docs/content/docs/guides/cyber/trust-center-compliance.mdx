**Replace static compliance spreadsheets with live API-backed trust posture.** Enterprise buyers and CI pipelines read the exact same control evidence from `/v1/trust`, `/v1/compliance`, and `/v1/risk`.

## Architecture & contract

`/v1/trust` tracks frameworks, controls, policies, and attached evidence; `/v1/compliance` records verifications and audit decisions; `/v1/risk/score` evaluates structured risk features before sensitive actions.

**Primary endpoint:** `GET /v1/trust/coverage/{framework}` · **Status:** `shipped` · **Level:** `architect`

<Tab value="TypeScript">
```ts
import { Configuration, TrustApi, ComplianceApi, RiskApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [cov, status, risk] = await Promise.all([
  new TrustApi(cfg).getTrustCoverageByFramework('soc2'),
  new ComplianceApi(cfg).getComplianceStatus(),
  new RiskApi(cfg).postRiskScore({ subject: 'release-v1.4', features: { open_criticals: 0 } }),
]);
console.log({ cov: cov.data, status: status.data, risk: risk.data });
```

<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import TrustApi, ComplianceApi, RiskApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(TrustApi(client).get_trust_coverage_by_framework("soc2"))
print(ComplianceApi(client).get_compliance_status())
print(RiskApi(client).post_risk_score({"subject": "release-v1.4", "features": {"open_criticals": 0}}))
```
