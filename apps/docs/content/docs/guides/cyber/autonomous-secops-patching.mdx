**Shrink mean-time-to-remediate from weeks to minutes without sacrificing human merge control.** Pair confirmed reproducers with `zen6-coder` inside a review-gated automation.

## Architecture & contract

The automation checks out an isolated branch, verifies the reproducer fails on base, authors the smallest fix, runs the full test suite plus `POST /v1/security/scans`, and pauses at `review` for security sign-off.

**Primary endpoint:** `POST /v1/auto/automations` · **Status:** `shipped` · **Level:** `specialist`
