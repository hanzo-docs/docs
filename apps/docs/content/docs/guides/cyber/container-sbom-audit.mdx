**Never promote a container image whose dependency tree you cannot enumerate.** `GET /v1/sbom/{ref}` inspects every package inside an OCI image addressed by immutable SHA-256 digest.

## Architecture & contract

Address images by digest (`registry/repo@sha256:...`) rather than mutable `:latest` tags so the SBOM you audit in CI is byte-identical to the image Kubernetes pulls.

**Primary endpoint:** `GET /v1/sbom/{ref}` · **Status:** `shipped` · **Level:** `practitioner`
