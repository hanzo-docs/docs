**Expose zero public ports on your private GPU workers and internal databases.** `/v1/network` builds an identity-authenticated zero-trust overlay across cloud clusters, edge nodes, and developer workstations.

## Architecture & contract

Each node receives a cryptographic identity enrolled via Hanzo IAM; traffic flows strictly between explicitly authorized identities and services with end-to-end encryption.

**Primary endpoint:** `GET /v1/network/identities` · **Status:** `shipped` · **Level:** `architect`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>

<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, NetworkApi } from 'hanzoai';

const net = new NetworkApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const [identities, services, routers] = await Promise.all([
  net.getNetworkIdentities(),
  net.getNetworkServices(),
  net.getNetworkRouters(),
]);
console.log({ identities: identities.data, services: services.data, routers: routers.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import NetworkApi

api = NetworkApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
print(api.get_network_identities())
print(api.get_network_services())
print(api.get_network_routers())
```
