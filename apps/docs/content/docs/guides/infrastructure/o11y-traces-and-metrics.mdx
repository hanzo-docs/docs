**You cannot optimize latency or unit economics in the dark.** Hanzo tags every model, tool, and HTTP span by org and project so observability and billing share one source of truth.

## Architecture & contract

`/v1/eval/metrics` summarizes GenAI spans (generations, tokens, cents, error rate, p50/p95 latency); `/v1/metrics/*` serves raw PromQL, log, and trace queries; `/v1/o11y/alerts` manages operational alerting.

**Primary endpoint:** `GET /v1/eval/metrics` · **Status:** `shipped` · **Level:** `practitioner`

```ts
import { Configuration, EvalApi, MetricsApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [aiMetrics, health] = await Promise.all([
  new EvalApi(cfg).getEvalMetrics('24h'),
  new MetricsApi(cfg).getMetricsHealth(),
]);
console.log({ aiMetrics: aiMetrics.data, health: health.data });
```

```python
import os
```

## Verify the outcome

- Assert `GET /v1/eval/metrics?range=24h` reflects recent model calls with accurate per-model latency breakdowns.

## Production guardrails

- Alert on `error_rate > 1%` and `p95_latency_ms` regressions rather than average latency alone.
