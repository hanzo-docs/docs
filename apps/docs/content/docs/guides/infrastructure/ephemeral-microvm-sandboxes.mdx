**Never run agent-generated code on your host kernel or shared build runner.** `/v1/sandbox` leases fast, hardware-isolated microVMs for every untrusted build, test run, or evaluation harness.

## Architecture & contract

Each sandbox has an isolated filesystem (`/v1/sandbox/{id}/fs`), exec interface (`/v1/sandbox/{id}/exec`), optional preview ports, and automatic TTL teardown so leaked processes cannot outlive a run.

**Primary endpoint:** `POST /v1/sandbox/lease` · **Status:** `shipped` · **Level:** `practitioner`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo sandbox quota
SANDBOX_ID=$(hanzo sandbox lease --data '{"image":"node:22-alpine","ttl_seconds":300}' | jq -r '.id')
hanzo sandbox exec "$SANDBOX_ID" --data '{"cmd":["node","-v"]}'
hanzo sandbox stop --data "{"id":"${SANDBOX_ID}"}"
```

<Tab value="TypeScript">
```ts
import { Configuration, SandboxApi } from 'hanzoai';

const sb = new SandboxApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data: lease } = await sb.postSandboxLease({ image: 'node:22-alpine', ttl_seconds: 300 });
try {
  const { data: res } = await sb.postSandboxByIdExec(lease.id, { cmd: ['node', '-v'] });
  console.log(res);
} finally {
  await sb.postSandboxStop({ id: lease.id });
}
```

<Tab value="HTTP">
```bash
SANDBOX_ID=$(curl -s -X POST https://api.hanzo.ai/v1/sandbox/lease \
  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
  -d '{"image":"node:22-alpine","ttl_seconds":300}' | jq -r '.id')

curl -s -X POST "https://api.hanzo.ai/v1/sandbox/${SANDBOX_ID}/exec" \
  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
  -d '{"cmd":["node","-v"]}' | jq '.'

curl -s -X POST https://api.hanzo.ai/v1/sandbox/stop \
  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
  -d "{"id":"${SANDBOX_ID}"}"
```

## Verify the outcome

- Confirm stdout prints the expected Node version and `stop` returns HTTP 200.

## Production guardrails

- Never pass long-lived `sk-` admin keys into sandbox environment variables; inject only short-lived scoped tokens when strictly needed.
