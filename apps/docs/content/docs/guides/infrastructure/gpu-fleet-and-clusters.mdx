**Run training and inference across Hanzo managed GPUs or your own bare-metal fleet through one compute API.** `/v1/compute` unifies GPU inventory, cluster pools, machines, and BYO fleet workers.

## Architecture & contract

Managed GPU clusters expose pool scaling (`POST /v1/compute/clusters/{clusterId}/pools/{poolId}/scale`), while your own on-premise GPUs register as fleet workers (`/v1/compute/fleet/workers`) capable of claiming `/v1/train/jobs`.

**Primary endpoint:** `GET /v1/compute/gpus` · **Status:** `shipped` · **Level:** `architect`

<Tab value="TypeScript">
```ts
import { Configuration, ComputeApi } from 'hanzoai';

const compute = new ComputeApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const [gpus, clusters, fleet] = await Promise.all([
  compute.getComputeGpus(),
  compute.getComputeClusters(),
  compute.getComputeFleetWorkers(),
]);
console.log({ gpus: gpus.data, clusters: clusters.data, fleet: fleet.data });
```
</Tab>

import os

print(api.get_compute_fleet_workers())

## Verify the outcome

- Check `GET /v1/compute/gpus/alerts` returns zero thermal or ECC hardware alerts before launching multi-hour training jobs.

## Production guardrails

- Configure idle scale-to-zero on dev GPU pools and monitor device-second rates on `GET /v1/train/models`.
