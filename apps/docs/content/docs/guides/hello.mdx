Build, verify, and ship a production multi-tenant AI application end-to-end: confirm gateway reachability and key scopes, load encrypted secrets from **Hanzo KMS**, publish durable **JetStream PubSub** events, and deploy static + serverless workloads to **Hanzo Sites & Zero-Trust K8s**.

## 1. Verify Gateway Reachability & API Key Scope

`GET /v1/models` is public by design (confirming network reachability without credentials), while `GET /v1/account/keys` enforces strict bearer authentication and returns your key's tenant scope (`sk-` server secret keys vs `pk-` browser publishable keys).

<Tabs items={['CLI', 'App', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
# Authenticate via Hanzo IAM (hanzo.id) and verify active keys
hanzo auth login
hanzo models list
hanzo account keys list
```
</Tab>
<Tab value="App">
1. Sign in at [hanzo.app](https://hanzo.app) or [platform.hanzo.ai/api-keys](https://platform.hanzo.ai/api-keys).
2. Mint a server `sk-...` key for backend compute and a `pk-...` key for browser telemetry.
3. Describe your full-stack app in **Hanzo App** or click **Deploy with Hanzo** on any GitHub/Forge repo.

## 2. Wire IAM OIDC, KMS Secrets & JetStream PubSub

Every service in your app shares one identity plane (`/v1/iam`), reads zero-trust runtime secrets from `/v1/kms`, and emits asynchronous domain events over `/v1/pubsub`:

<Tabs items={['CLI', 'TypeScript SDK', 'Python SDK', 'HTTP']}>
<Tab value="CLI">
```bash
# Store encrypted project secrets in Hanzo KMS
hanzo kms secrets set WEBHOOK_SIGNING_SECRET "whsec_prod_..."

# Publish a durable JetStream event for background workers
hanzo pubsub publish app.deployments '{"project":"acme-web","env":"production"}'
```
</Tab>
<Tab value="TypeScript SDK">
```ts
import { Configuration, PubsubApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const pubsub = new PubsubApi(cfg);

// Verify OIDC discovery + emit a typed deployment event
const oidc = await fetch('https://api.hanzo.ai/v1/iam/.well-known/openid-configuration').then((r) => r.json());
await pubsub.postPubsubPublish({
  subject: 'app.deployments',
  data: { issuer: oidc.issuer, project: 'acme-web', deployedAt: new Date().toISOString() },
});
```
</Tab>
<Tab value="Python SDK">
```python
# pip install "hanzoai>=8"
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import PubsubApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
PubsubApi(client).post_pubsub_publish(
    body={"subject": "app.deployments", "data": {"project": "acme-web", "status": "live"}}
)
```
</Tab>
<Tab value="HTTP">
```bash
# Read OIDC configuration for multi-tenant login
curl -fsSL https://api.hanzo.ai/v1/iam/.well-known/openid-configuration

# Fetch runtime secrets from Hanzo KMS
curl -fsSL https://api.hanzo.ai/v1/kms/secrets/acme-web \
  -H "Authorization: Bearer $HANZO_API_KEY"

# Publish a JetStream event
curl -X POST https://api.hanzo.ai/v1/pubsub/publish \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"subject":"app.deployments","data":{"project":"acme-web"}}'
```

## 3. Deploy Edge Sites, Serverless Functions & Zero-Trust K8s

Move seamlessly from local iteration (`hanzo up`) to global edge static hosting (`/v1/project/{slug}/deploy`), serverless functions (`/v1/function`), and GitOps Kubernetes reconciliation (`/v1/deploy/applications`):

```bash
# 1. Test full stack locally on warm k3s
hanzo up

# 2. Ship static frontend + edge routes to Hanzo Sites and Zero-Trust K8s
hanzo deploy --project acme-web

# 3. Verify live deployment & serverless functions over HTTP
curl -X POST https://api.hanzo.ai/v1/project/acme-web/deploy \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"branch":"main"}'

curl -fsSL https://api.hanzo.ai/v1/deploy/applications \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
