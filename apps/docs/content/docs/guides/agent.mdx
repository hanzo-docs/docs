Run stateful coding, security, and operations agents backed by **`hanzoai/gen`** (`/v1/agent`), hardware-isolated **`hanzoai/vm` + `visor`** microVM sandboxes (`/v1/sandbox`), copy-on-write **`hanzoai/vfs`** filesystem snapshots, and deterministic **Kai** completion gates.

## 1. Create, Run & Poll a Stateful Autonomous Agent

Agent runs execute asynchronously with durable turn histories, tool permissions, and per-agent spend tracking. Address agents by either their `agent_...` ID or org-unique slug (`ref`):

<Tabs items={['CLI', 'App', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
# Create an agent with Enso routing and HIP-0300 MCP tools
hanzo agent create --data '{"name":"pr-reviewer","model":"enso-pro"}'

# Trigger an asynchronous run and inspect run history + spend
hanzo agent run pr-reviewer --data '{"input":"Audit PR #142 for SQL injection and race conditions"}'
hanzo agent runs pr-reviewer
```
</Tab>

## 2. Isolate Untrusted Execution in MicroVM Sandboxes (`/v1/sandbox`)

Never run agent-generated shell commands or untrusted patches on shared host kernels. Provision an ephemeral microVM backed by `hanzoai/vm`, `visor`, and `vfs`, run commands, inspect files, pause/snapshot state, and expose preview ports:

```bash
# 1. Boot an isolated microVM sandbox
SANDBOX_ID=$(curl -fsSL -X POST https://api.hanzo.ai/v1/sandbox \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"image":"hanzoai/dev-sandbox:latest","cpu":2,"memoryMb":4096}' | jq -r '.id')

# 2. Execute build & test commands inside the microVM
curl -X POST "https://api.hanzo.ai/v1/sandbox/$SANDBOX_ID/exec" \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"cmd":["cargo","test","--workspace"],"cwd":"/workspace"}'

# 3. Pause & snapshot VFS state between agent turns so cold-resume takes milliseconds
curl -X POST "https://api.hanzo.ai/v1/sandbox/$SANDBOX_ID/pause" \
  -H "Authorization: Bearer $HANZO_API_KEY"
```

## 3. Coordinate Multi-Agent Swarms Over A2A (`/v1/agent/a2a`)

Compose specialized planner, implementer, security-auditor, and verifier agents via Agent-to-Agent (`POST /v1/agent/a2a`) handoffs gated by Kai Decision Programs (`POST /v1/decisions`):

```bash
curl -X POST https://api.hanzo.ai/v1/agent/a2a \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "architect-agent",
    "to": "pr-reviewer",
    "task": "Verify migration 0042 inside a fresh sandbox and report pass/fail evidence."
  }'
```
