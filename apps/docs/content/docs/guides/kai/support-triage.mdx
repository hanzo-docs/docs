**Running 100,000 500-token support triage decisions on Kai costs `$1.05` total — with zero output tokens.** Reserve generative compute (`zen6`) strictly for writing the final customer reply.

## Architecture & contract

Combine `POST /v1/decisions` (three typed questions in one CPU forward pass) with `POST /v1/chat/completions` (`model: "zen6"`). Tickets that fail Kai's confidence threshold skip automated reply generation and route directly to a human specialist.

**Primary endpoint:** `POST /v1/decisions` · **Status:** `shipped` · **Level:** `practitioner`

# 1. Classify ticket with Kai

  }
}')
echo "$DEC" | jq '.answers'

# 2. Draft grounded reply with Zen 6
hanzo chat completions --data '{"model":"zen6","messages":[{"role":"user","content":"Draft a concise 2-sentence troubleshooting reply for webhook signature failure after secret rotation."}]}'

```ts
import { Configuration, AiApi } from 'hanzoai';

const ai = new AiApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const ticket = 'Our webhook signature verification fails after rotating our signing secret.';
const { data: dec } = await ai.postDecisions({
  model: 'kai',
  state: ticket,
  questions: {
    team: {
      type: 'choice',
      instructions: 'Owner team?',
      criteria: { billing: 'Payments', platform: 'Webhooks, APIs, SDKs', security: 'Keys and auth' },
    },
  },
});
const queue = dec.answers.team.confidence >= 0.65 ? dec.answers.team.choice : 'manual_triage';
const { data: reply } = await ai.postChatCompletions({
  model: 'zen6',
  messages: [
    { role: 'system', content: `You represent the ${queue} team. Two concise sentences.` },
    { role: 'user', content: ticket },
  ],
});
console.log({ queue, reply });
```

<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import AiApi

api = AiApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
ticket = "Our webhook signature verification fails after rotating our signing secret."
dec = api.post_decisions({
    "model": "kai",
    "state": ticket,
    "questions": {
        "team": {
            "type": "choice",
            "instructions": "Owner team?",
            "criteria": {"billing": "Payments", "platform": "Webhooks, APIs, SDKs", "security": "Keys and auth"},
        }
    },
})
queue = dec["answers"]["team"]["choice"] if dec["answers"]["team"]["confidence"] >= 0.65 else "manual_triage"
reply = api.post_chat_completions(
    model="zen6",
    messages=[{"role": "system", "content": f"You represent the {queue} team. Two concise sentences."}, {"role": "user", "content": ticket}],
)
print(queue, reply)
```
