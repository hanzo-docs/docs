**An uncalibrated classifier fails silently on ambiguous inputs.** Kai returns both `answer_confidence` (`p_max`) and normalized `confidence` (`(n·p_max - 1)/(n - 1)`), so one abstention threshold works identically across 3-class and 30-class decisions.

## Architecture & contract

When `confidence` is `0`, every option is equally likely; when `confidence` is `1`, one option carries all probability mass. Set a conservative threshold (such as `>= 0.70`) for automated actions and route everything below it to a human queue or `zen6`.

**Primary endpoint:** `POST /v1/decisions` · **Status:** `shipped` · **Level:** `practitioner`

## Verify the outcome

- Multi-intent tickets should drop below `0.70` confidence and trigger `escalate`.
- Single-intent tickets should exceed `0.85` confidence and route automatically.

## Production guardrails

- Tune thresholds empirically on held-out org datasets (`/v1/eval/datasets`) rather than guessing.
- Pin `routing.calibration` beside your thresholds so calibration shifts drop to `shadow`.
