**Autonomous agents fail in two symmetric ways: stopping after claiming success without running tests, or looping forever after tests already pass.** Gate loop exit with two calibrated Kai `noul` checks (`done` and `verified`).

## Architecture & contract

After every sandbox test execution, send the task specification, git diff summary, and raw test output as `state` to `POST /v1/decisions`. Exit the loop strictly when `answers.done.noul >= 0.65 && answers.verified.noul >= 0.65` AND the shell test command returned exit code `0`.

**Primary endpoint:** `POST /v1/decisions` · **Status:** `shipped` · **Level:** `specialist`

## Verify the outcome

- Feed a state with `test_exit_code: 1` and failing output — verify `verified` drops below `0.65` and the loop continues.
- Feed passing output and verify clean exit.

## Production guardrails

- Always combine Kai's semantic check with a deterministic exit-code check (`exit_code == 0`) and a hard `max_turns` budget.
