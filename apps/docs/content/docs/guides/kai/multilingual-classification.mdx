**Skip the translation step.** Kai uses a 51-language multilingual encoder (`256,000`-token vocabulary, `0.9096` macro accuracy on MASSIVE), letting you keep one English schema while classifying Spanish, Japanese, Arabic, French, or German inputs directly.

## Architecture & contract

The question and multilingual `state` encode through the shared backbone while each English option encodes independently and attends cross-lingually. Option encodings cache across calls regardless of input language.

**Primary endpoint:** `POST /v1/decisions` · **Status:** `shipped` · **Level:** `practitioner`

```ts
import { Configuration, AiApi } from 'hanzoai';

const ai = new AiApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data } = await ai.postDecisions({
  model: 'kai',
  state: '注文した商品が破損して届きました。全額返金をお願いできますか？',
  questions: {
    intent: {
      type: 'choice',
      instructions: 'What does the customer want?',
      criteria: {
        refund: 'Requesting money back',
        replacement: 'Requesting a replacement item',
        shipping_status: 'Asking where an order is',
      },
    },
  },
});
console.log(data.answers.intent);
```
