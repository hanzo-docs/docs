**A Decision Program separates what the model estimates from what policy permits.** Start every program in `shadow`, audit its agreement against real outcomes, and promote to `enforced` only when measured evidence justifies it.

## Architecture & contract

Every program defines `questions`, per-question `thresholds`, an escalation rule (`secret_exposure -> deny`, `network -> ask`), and a `mode` (`shadow`, `advisory`, or `enforced`). Under `enforced`, Kai can tighten your deterministic `base` verdict (`allow -> ask -> deny`) but can never loosen a deterministic `deny`.

**Primary endpoint:** `POST /v1/decisions` · **Status:** `shipped` · **Level:** `practitioner`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo decisions create --model kai --data '{
  "state": {"command": "rm -rf /var/lib/postgres/data"},
  "questions": {
    "verdict": {
      "type": "choice",
      "instructions": "Should the agent run this shell command?",
      "criteria": {
        "allow": "Read-only or confined to working repository",
        "ask": "Modifies shared files or contacts network",
        "deny": "Exposes secrets or destroys persistent data"
      }
    },
    "production_impact": {"type": "noul", "instructions": "Could this command destroy shared or production data?"}
  }
}'
```

<Tab value="TypeScript">
```ts
import { Configuration, AiApi } from 'hanzoai';

const rank = { allow: 0, ask: 1, deny: 2 } as const;
const ai = new AiApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data } = await ai.postDecisions({
  model: 'kai',
  state: { command: 'rm -rf /var/lib/postgres/data' },
  questions: {
    verdict: {
      type: 'choice',
      instructions: 'Should the agent run this shell command?',
      criteria: { allow: 'Read-only', ask: 'Writes or network', deny: 'Secrets or destructive' },
    },
    production_impact: { type: 'noul', instructions: 'Could this command destroy production data?' },
  },
});
const base: keyof typeof rank = 'allow';
const kaiVerdict: keyof typeof rank = data.answers.production_impact.noul >= 0.4 ? 'deny' : 'allow';
const effective = rank[kaiVerdict] > rank[base] ? kaiVerdict : base;
console.log({ base, kaiVerdict, effective });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import AiApi

RANK = {"allow": 0, "ask": 1, "deny": 2}
api = AiApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
res = api.post_decisions({
    "model": "kai",
    "state": {"command": "rm -rf /var/lib/postgres/data"},
    "questions": {
        "verdict": {
            "type": "choice",
            "instructions": "Should the agent run this shell command?",
            "criteria": {"allow": "Read-only", "ask": "Writes or network", "deny": "Secrets or destructive"},
        },
        "production_impact": {"type": "noul", "instructions": "Could this destroy production data?"},
    },
})
base = "allow"
kai_v = "deny" if res["answers"]["production_impact"]["noul"] >= 0.4 else "allow"
effective = kai_v if RANK[kai_v] > RANK[base] else base
print({"base": base, "kai": kai_v, "effective": effective})
```

## Verify the outcome

- Test `git status` (expect `allow`) vs `rm -rf /var/lib/postgres/data` (expect `deny`).
- Verify a deterministic `base = deny` stays `deny` even if Kai outputs `allow`.

## Production guardrails

- Always ship new Decision Programs in `shadow` first.
- Check `routing.calibration` matches your validated calibration hash before honoring `enforced`.
