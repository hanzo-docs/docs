**A single latest benchmark number cannot distinguish a model that improved from one that silently regressed.** Combine `GET /v1/benchmark/history` with live `GET /v1/eval/metrics` to catch drift early.

## Architecture & contract

`/v1/benchmark/history` returns chronologically ordered runs with run-to-run deltas; `/v1/eval/metrics` computes gap-filled time series and latency percentiles directly from your org's GenAI spans.

**Primary endpoint:** `GET /v1/benchmark/history` · **Status:** `shipped` · **Level:** `practitioner`

<Tab value="TypeScript">
```ts
import { Configuration, BenchmarkApi, EvalApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [history, metrics] = await Promise.all([
  new BenchmarkApi(cfg).getBenchmarkHistory('swe-bench-verified', 'zen6-coder'),
  new EvalApi(cfg).getEvalMetrics('7d'),
]);
console.log({ history: history.data, metrics: metrics.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import BenchmarkApi, EvalApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(BenchmarkApi(client).get_benchmark_history(benchmark="swe-bench-verified", model="zen6-coder"))
print(EvalApi(client).get_eval_metrics(range="7d"))
```
