**Make everyday coding and operations compound into stronger memory, skills, tools, and agent harnesses.** Recursive improvement works only when every proposed upgrade is scoped, evidence-backed, and reviewable.

## Architecture & contract

Local memory consolidation extracts reusable preferences without falling back to billed foreground models; Kai's `agent.learn@1` chooses `none`, `memory`, `experiment`, or `improvement` after verified tool turns; harness changes ship strictly as draft PRs validated on held-out evals.

**Primary endpoint:** `GET /v1/research/runs` · **Status:** `preview` · **Level:** `fellow`

import { Configuration, EvalApi, AiApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [metrics, feedback] = await Promise.all([
  new EvalApi(cfg).getEvalMetrics('7d'),
  new AiApi(cfg).postAiFeedback({ request_id: 'chatcmpl-01J...', signal: 'accept' }),
]);
