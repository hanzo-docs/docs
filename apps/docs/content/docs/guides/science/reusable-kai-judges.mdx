**A noisy judge invalidates every experiment downstream.** Register versioned, reusable evaluators on `/v1/eval/evaluators` backed by Kai (`0` output tokens, deterministic per weights hash) or exact programmatic checks.

## Architecture & contract

Evaluators key by `name` inside your org, binding a `judge_model`, written `criteria`, and `score_name`. Every evaluation run writes trace-linked scores queryable on `GET /v1/eval/scores` and `GET /v1/eval/runs`.

**Primary endpoint:** `POST /v1/eval/evaluators` · **Status:** `shipped` · **Level:** `practitioner`

```ts
import { Configuration, EvalApi } from 'hanzoai';

const evalApi = new EvalApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data } = await evalApi.postEvalEvaluators({
  name: 'grounding-check',
  judge_model: 'kai',
  score_name: 'grounded',
  criteria: 'Every factual claim in the answer is directly supported by the retrieved context.',
});
console.log(data);
```
