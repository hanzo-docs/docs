**Reproducibility starts with immutable data.** Materializing a dataset freezes the exact rows behind a training run or risk model so results can be audited months later.

## Architecture & contract

`POST /v1/dataset/{name}/materialize` produces a content-hashed snapshot linked to its parent transforms. `GET /v1/dataset/{name}/lineage` returns the full DAG from raw ingestion through filtering and labeling.

**Primary endpoint:** `POST /v1/dataset/{name}/materialize` · **Status:** `shipped` · **Level:** `practitioner`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo dataset create --data '{"name":"fraud-features-2026q4","description":"Labeled chargeback & transaction features"}'
hanzo dataset materialize fraud-features-2026q4
hanzo dataset lineage fraud-features-2026q4
hanzo dataset export fraud-features-2026q4
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, DatasetApi } from 'hanzoai';

const ds = new DatasetApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
await ds.postDataset({ name: 'fraud-features-2026q4', description: 'Labeled chargeback features' });
await ds.postDatasetByNameMaterialize('fraud-features-2026q4');
const { data: lineage } = await ds.getDatasetByNameLineage('fraud-features-2026q4');
console.log(lineage);
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import DatasetApi

api = DatasetApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
api.post_dataset({"name": "fraud-features-2026q4", "description": "Labeled chargeback features"})
api.post_dataset_by_name_materialize("fraud-features-2026q4")
print(api.get_dataset_by_name_lineage("fraud-features-2026q4"))
```
