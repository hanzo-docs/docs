## 1. Read Credit Balances & Windowed Usage Ledgers

Tenant scope is derived cryptographically from the caller's bearer credential (`owner` claim) — a key can only ever inspect its own organization's ledger:

<Tabs items={['CLI', 'App', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
# Check live credit balance and itemized usage across models, sandboxes, and storage
hanzo billing balance
hanzo billing usage
```
</Tab>
<Tab value="App">
Open [platform.hanzo.ai/billing](https://platform.hanzo.ai) or **Hanzo Desktop**:

1. View real-time token, sandbox, and storage burn broken down by model family, project, and individual agent (`GET /v1/agent/{ref}/spend`).
2. Configure hard spend caps, auto-topup thresholds, and SaaS subscription plans.
</Tab>

## 2. Enforce Spend Alerts, Subscriptions & Commerce Catalogs

Combine `/v1/billing/alerts` budget guardrails with `hanzoai/commerce` (`/v1/commerce/catalog`, `/v1/commerce/cart`, `/v1/billing/subscriptions`) to monetize your own AI SaaS, APIs, or Marketplace agents:

```bash
# 1. Arm an automated org budget alert before spend crosses threshold
curl -X POST https://api.hanzo.ai/v1/billing/alerts \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"thresholdCents":10000,"channels":["email","webhook"]}'

# 2. Read live SaaS plans, model SKUs, and active subscriptions
curl -fsSL https://api.hanzo.ai/v1/commerce/catalog \
  -H "Authorization: Bearer $HANZO_API_KEY"
curl -fsSL https://api.hanzo.ai/v1/billing/subscriptions \
  -H "Authorization: Bearer $HANZO_API_KEY"
```

## 3. Headless Agent Wallets, x402 Micropayments & USDC Settlement

Provision programmable wallets (`/v1/wallet`) and settle headless machine-to-machine checkouts with Stripe Shared Payment Tokens (`spt_...`), HTTP `402 Payment Required` (`x402`) headers, or on-chain USDC deposits across Base, Solana, and Tempo:

```bash
# 1. Provision an agent wallet for x402 micropayments
curl -X POST https://api.hanzo.ai/v1/wallet \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"research-agent-wallet","network":"base"}'

# 2. Open and complete a headless checkout or USDC top-up
curl -fsSL https://api.hanzo.ai/v1/billing/discovery
curl -X POST https://api.hanzo.ai/v1/billing/topup/crypto \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amountCents":2500,"network":"base"}'
```
