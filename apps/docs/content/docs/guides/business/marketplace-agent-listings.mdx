**Distribute your agents, MCP tools, and vertical templates directly to Hanzo organizations.** `/v1/marketplace` handles discovery, installation, escrow-backed delivery, and seller payouts.

## Architecture & contract

Listings carry structured schemas and verification state (`/v1/marketplace/listings/{id}/verify`). Jobs follow a clean auditable state machine (`accept` → `deliver` → `release` or `dispute`) settled against verified seller payout accounts.

**Primary endpoint:** `GET /v1/marketplace/listings` · **Status:** `shipped` · **Level:** `practitioner`

<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, MarketplaceApi } from 'hanzoai';

const mkt = new MarketplaceApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const [listings, jobs] = await Promise.all([
  mkt.getMarketplaceListings(),
  mkt.getMarketplaceJobs(),
]);
console.log({ listings: listings.data, jobs: jobs.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import MarketplaceApi

api = MarketplaceApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
print(api.get_marketplace_listings())
print(api.get_marketplace_jobs())
```
