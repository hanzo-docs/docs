**Meter every token, decision, and GPU-second from the same authoritative ledger the gateway debits.** Build accurate usage dashboards, overage alerts, and automated customer invoicing.

## Architecture & contract

Tenant scope derives server-side from the verified credential so one org can never read another org's financial data. Window `/v1/billing/usage` with ISO `start` and `end` parameters to reconcile monthly invoices against `GET /v1/billing/ledger`.

**Primary endpoint:** `GET /v1/billing/usage` · **Status:** `shipped` · **Level:** `practitioner`

<Tab value="TypeScript">
```ts
import { Configuration, BillingApi } from 'hanzoai';

const billing = new BillingApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const [bal, usage, ledger] = await Promise.all([
  billing.getBillingBalance(),
  billing.getBillingUsage(),
  billing.getBillingLedger(),
]);
console.log({ balance: bal.data, usage: usage.data, ledger: ledger.data });
```
