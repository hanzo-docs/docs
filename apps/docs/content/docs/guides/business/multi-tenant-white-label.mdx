**Ship enterprise-grade multi-tenancy on day one.** Every customer organization gets its own IAM identity boundary, Base store, KMS namespace, and plan entitlement resolution.

## Architecture & contract

Resolve tenant entitlements server-side from IAM-verified org claims (`GET /v1/entitlement/orgs/{org}`) before opening Base queries (`/v1/base/bases/{org}`) or routing into paid model tiers.

**Primary endpoint:** `GET /v1/entitlement/orgs/{org}` · **Status:** `shipped` · **Level:** `architect`

```ts
import { Configuration, PlanApi, EntitlementApi, BaseApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [plans, ent, base] = await Promise.all([
  new PlanApi(cfg).getPlan(),
  new EntitlementApi(cfg).getEntitlementOrgsByOrg('acme-corp'),
  new BaseApi(cfg).getBaseBasesByOrg('acme-corp'),
]);
console.log({ plans: plans.data, ent: ent.data, base: base.data });
```
