## Hanzo MCP

Two ways to give Windsurf Hanzo's tools. **API key** is the hosted endpoint, [`https://api.hanzo.ai/v1/mcp`](/docs/mcp-tools), with a key from [hanzo.app](https://hanzo.app) sent as `Authorization: Bearer sk-...`. **Local** is `hanzo-mcp` on your machine, started with `npx -y hanzo mcp` (needs Node.js). With no key set it uses the sign-in `hanzo login` stored, so there is no key to paste ([MCP](/docs/mcp)). Replace `sk-...` with your key.

<Tabs items={["API key","Local"]}>
<Tab value="API key">
{/* verified against https://docs.windsurf.com/plugins/cascade/mcp */}
In Cascade, open the MCP menu and choose `Open MCP config file` (`~/.config/devin/mcp_config.json`), then add this.

```json
{
  "mcpServers": {
    "hanzo-cloud": {
      "serverUrl": "https://api.hanzo.ai/v1/mcp",
      "headers": {
        "Authorization": "Bearer sk-..."
      }
    }
  }
}
```
</Tab>
<Tab value="Local">
{/* verified against https://docs.windsurf.com/plugins/cascade/mcp */}
In Cascade, open the MCP menu and choose `Open MCP config file`, then add this.

```json
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "hanzo", "mcp"]
    }
  }
}
```
</Tab>
</Tabs>

Cascade's `Open MCP config file` action opens `~/.config/devin/mcp_config.json` on macOS and Linux and `%AppData%\devin\mcp_config.json` on Windows. A `mcp_config.json` can also sit in a project at `.devin/mcp_config.json`.
