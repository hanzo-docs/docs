## Set up

```bash
curl -fsSL hanzo.sh | sh      # or, on any OS: npm i -g hanzo
hanzo login
hanzo dev
```

Bare `hanzo` starts the same agent. Hanzo Dev reads its configuration from `~/.hanzo/dev/config.toml` and nothing from a `.codex` beside it.

## Hanzo MCP

Two ways to give Hanzo Dev Hanzo's tools. **API key** adds the hosted endpoint, [`https://api.hanzo.ai/v1/mcp`](/docs/mcp-tools), with a key from [hanzo.app](https://hanzo.app) sent as `Authorization: Bearer sk-...`. **Local** is `hanzo-mcp`, which Hanzo Dev starts with. Replace `sk-...` with your key.

Add to `~/.hanzo/dev/config.toml`.

```toml
[mcp_servers.hanzo-cloud]
url = "https://api.hanzo.ai/v1/mcp"
http_headers = { Authorization = "Bearer sk-..." }
```

```toml
[mcp_servers.hanzo]
command = "hanzo-mcp"
args = []
```
