## Hanzo MCP

Two ways to give Warp Hanzo's tools. **API key** is the hosted endpoint, [`https://api.hanzo.ai/v1/mcp`](/docs/mcp-tools), with a key from [hanzo.app](https://hanzo.app) sent as `Authorization: Bearer sk-...`. **Local** is `hanzo-mcp` on your machine, started with `npx -y hanzo mcp` (needs Node.js). With no key set it uses the sign-in `hanzo login` stored, so there is no key to paste ([MCP](/docs/mcp)). Replace `sk-...` with your key.

<Tabs items={["API key","Local"]}>
<Tab value="API key">
{/* verified against https://docs.warp.dev/agents/capabilities/mcp */}
In Warp, open `Settings > Agents > MCP servers`, choose `+ Add` and paste this.

```json
{
  "mcpServers": {
    "hanzo-cloud": {
      "url": "https://api.hanzo.ai/v1/mcp",
      "headers": {
        "Authorization": "Bearer sk-..."
      }
    }
  }
}
```
</Tab>
<Tab value="Local">
{/* verified against https://docs.warp.dev/agents/capabilities/mcp */}
In Warp, open `Settings > Agents > MCP servers`, choose `+ Add` and paste this.

```json
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "hanzo", "mcp"]
    }
  }
}
```
</Tab>
</Tabs>
