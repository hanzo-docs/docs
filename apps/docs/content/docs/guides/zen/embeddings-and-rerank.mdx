**Vector search gets recall; cross-encoder reranking gets precision.** Pair `POST /v1/embeddings` (`zen-embedding`) with `POST /v1/rerank` (`zen-reranker`) before feeding context into Zen 6 or Kai.

## Architecture & contract

Encode documents once and store vectors in `/v1/index` or `/v1/base`. At query time, retrieve top-50 candidates by cosine similarity, then score `(query, candidate)` pairs with `POST /v1/rerank` to select the top-5 passages.

**Primary endpoint:** `POST /v1/embeddings` · **Status:** `shipped` · **Level:** `practitioner`

```ts
const headers = { Authorization: `Bearer ${process.env.HANZO_API_KEY}`, 'Content-Type': 'application/json' };
const emb = await fetch('https://api.hanzo.ai/v1/embeddings', {
  method: 'POST', headers,
  body: JSON.stringify({ model: 'zen-embedding', input: ['Kai answers bounded questions.', 'Enso routes prompts.'] }),
}).then((r) => r.json());

const ranked = await fetch('https://api.hanzo.ai/v1/rerank', {
  method: 'POST', headers,
  body: JSON.stringify({ model: 'zen-reranker', query: 'bounded classification', documents: ['Kai answers bounded questions.', 'Enso routes prompts.'] }),
}).then((r) => r.json());
console.log({ dims: emb.data?.[0]?.embedding?.length, ranked });
```

## Verify the outcome

- Assert the top reranked document matches the exact semantic target with a clearly separated relevance score.

## Production guardrails

- Never mix `zen-embedding` and `zen-embedding-3` vectors in the same index — rebuild the index whenever upgrading embedding models.
