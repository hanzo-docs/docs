**Optimize directly for passing tests and domain rubrics instead of static imitation.** `/v1/train/clients` gives your trainer remote `sample`, `forward_backward`, `optim_step`, and `save_weights` primitives over managed GPUs.

## Architecture & contract

Your trainer loops over prompts, samples `K` candidate generations per prompt, evaluates each in `/v1/sandbox` + Kai (`POST /v1/decisions`), normalizes group advantages, sends gradients through `forward_backward`, steps the optimizer, and checkpoints via `save_weights`.

**Primary endpoint:** `POST /v1/train/clients` · **Status:** `shipped` · **Level:** `architect`

```ts
import { Configuration, TrainApi } from 'hanzoai';

const train = new TrainApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data: c } = await train.postTrainClients({ base_model: 'zen6-flash', lora_rank: 16 });
try {
  const { data: samples } = await train.postTrainClientsByIdSample(c.id, { prompts: ['Write a URL-safe base64 encoder in Rust.'], n: 4 });
  await train.postTrainClientsByIdForwardBackward(c.id, { batch: samples });
  await train.postTrainClientsByIdOptimStep(c.id, { learning_rate: 1e-5 });
  await train.postTrainClientsByIdSaveWeights(c.id, { name: 'zen6-flash-grpo-v1' });
} finally {
  await train.deleteTrainClientsById(c.id);
}
```

<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import TrainApi

api = TrainApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
c = api.post_train_clients({"base_model": "zen6-flash", "lora_rank": 16})
try:
    samples = api.post_train_clients_by_id_sample(c["id"], {"prompts": ["Write a URL-safe base64 encoder in Rust."], "n": 4})
    api.post_train_clients_by_id_forward_backward(c["id"], {"batch": samples})
    api.post_train_clients_by_id_optim_step(c["id"], {"learning_rate": 1e-5})
    api.post_train_clients_by_id_save_weights(c["id"], {"name": "zen6-flash-grpo-v1"})
finally:
    api.delete_train_clients_by_id(c["id"])
```

<Tab value="HTTP">
```bash
CLIENT_ID=$(curl -s -X POST https://api.hanzo.ai/v1/train/clients \
  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
  -d '{"base_model":"zen6-flash","lora_rank":16}' | jq -r '.id')

curl -s -X POST "https://api.hanzo.ai/v1/train/clients/${CLIENT_ID}/sample" \
  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
  -d '{"prompts":["Write a URL-safe base64 encoder in Rust."],"n":4}' | jq '.'

curl -s -X DELETE "https://api.hanzo.ai/v1/train/clients/${CLIENT_ID}" \
  -H "Authorization: Bearer $HANZO_API_KEY"
```

## Production guardrails

- Always wrap client lifecycle in `try / finally` calling `DELETE /v1/train/clients/{id}` to prevent idle GPU charges.
