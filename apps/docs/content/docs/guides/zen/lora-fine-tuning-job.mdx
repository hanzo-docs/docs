**Fine-tune open-weight Zen models with content-addressed provenance and metered GPU billing.** Every dataset and resulting LoRA adapter is verified by SHA-256.

## Architecture & contract

Register input bytes on `/v1/train/artifacts`, launch a LoRA job on `/v1/train/jobs` targeting managed GPUs or your registered BYO fleet, stream status via long-polled `/events`, and inspect validation series on `/metrics`.

**Primary endpoint:** `POST /v1/train/jobs` · **Status:** `shipped` · **Level:** `specialist`

## Run it across all four surfaces


<Tab value="TypeScript">
```ts
import { Configuration, TrainApi } from 'hanzoai';

const train = new TrainApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data: job } = await train.postTrainJobs({
  base_model: 'zen6-flash',
  adaptation: 'lora',
  dataset_sha256: process.env.DATASET_SHA256!,
  hyperparameters: { epochs: 3, learning_rate: 2e-4, lora_rank: 16 },
});
console.log('Submitted job:', job);
```

```python
import os

    "base_model": "zen6-flash",
    "adaptation": "lora",
    "dataset_sha256": os.environ["DATASET_SHA256"],
    "hyperparameters": {"epochs": 3, "learning_rate": 2e-4, "lora_rank": 16},
})
print(job)
```

## Verify the outcome

- Stream `GET /v1/train/jobs/{id}/metrics` and confirm validation loss declines without diverging from training loss.

## Production guardrails

- Scan corpora with `POST /v1/security/scans` before uploading to `/v1/train/artifacts` so secrets never enter weights.
