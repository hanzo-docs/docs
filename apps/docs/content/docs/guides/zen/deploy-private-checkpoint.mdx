**A checkpoint on S3 does nothing until it clears its regression budget and routes behind a stable org model name.** Publish completed artifacts atomically via `POST /v1/train/jobs/{id}/publish` or `POST /v1/ai/finetune/deploy`.

## Architecture & contract

Only jobs whose validation suites pass their declared regression budget publish cleanly without an audited `force` override. Published checkpoints inherit tenant IAM boundaries and bill under your org ledger.

**Primary endpoint:** `POST /v1/train/jobs/{id}/publish` · **Status:** `shipped` · **Level:** `specialist`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo train jobs artifacts get "$JOB_ID"
hanzo train jobs publish "$JOB_ID" --data '{"name":"zen6-flash-legal-v1"}'
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, TrainApi } from 'hanzoai';

const train = new TrainApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const arts = await train.getTrainJobsByIdArtifacts(process.env.JOB_ID!);
const pub = await train.postTrainJobsByIdPublish(process.env.JOB_ID!, { name: 'zen6-flash-legal-v1' });
console.log({ artifacts: arts.data, published: pub.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import TrainApi

api = TrainApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
job_id = os.environ["JOB_ID"]
print(api.get_train_jobs_by_id_artifacts(job_id))
print(api.post_train_jobs_by_id_publish(job_id, {"name": "zen6-flash-legal-v1"}))
```

<Tab value="HTTP">
