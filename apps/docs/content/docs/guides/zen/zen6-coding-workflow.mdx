**Own your coding intelligence with Apache-2.0 Zen 6 weights.** `zen6` reads up to `1,000,000` tokens hosted and runs identically on your own hardware or on `api.hanzo.ai`.

## Architecture & contract

`zen6` is a 27.3B dense hybrid linear/full-attention architecture with bundled speculative drafting; `zen6-coder` optimizes multi-file editing and tool calling. Both speak the standard `/v1/chat/completions` wire.

**Primary endpoint:** `POST /v1/chat/completions` · **Status:** `shipped` · **Level:** `foundations`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo chat completions --data '{
  "model": "zen6-coder",
  "messages": [{"role": "user", "content": "Write a thread-safe token bucket rate limiter in Go with unit tests."}]
}'
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, AiApi } from 'hanzoai';

const ai = new AiApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data } = await ai.postChatCompletions({
  model: 'zen6-coder',
  messages: [{ role: 'user', content: 'Write a thread-safe token bucket rate limiter in Go with unit tests.' }],
});
console.log(data);
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import AiApi

api = AiApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
print(api.post_chat_completions(
    model="zen6-coder",
    messages=[{"role": "user", "content": "Write a thread-safe token bucket rate limiter in Go with unit tests."}],
))
```
</Tab>
</Tabs>
</Tab>
<Tab value="HTTP">
```bash
curl -s https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen6-coder",
    "messages": [{"role": "user", "content": "Write a thread-safe token bucket rate limiter in Go with unit tests."}]
  }' | jq -r '.choices[0].message.content'
```
</Tab>
<Tab value="MCP">

      "arguments": {"op": "get_code_health", "input": {}}
