Give any coding agent, IDE, or autonomous bot two unified tool layers with one API key:

1. **Local HIP-0300 Workspace MCP (`@hanzo/mcp`)** — 19 orthogonal operator tools (`fs`, `exec`, `code`, `git`, `fetch`, `browser`, `computer`, `memory`, `plan`, `kai`, `agent`, `think`, `ui`, `workspace`, and peers) designed to keep context token footprint minimal.
2. **Hosted Cloud MCP (`POST https://api.hanzo.ai/v1/mcp` & `GET /v1/tool`)** — zero-install Streamable HTTP access to ~110 Hanzo Cloud capabilities plus Slack, GitHub, GitLab, Linear, Discord, and Notion connectors.

## 1. Attach HIP-0300 MCP to Every Coding Agent & IDE

```bash
# Claude Code (user-wide across every repository)
claude mcp add --scope user hanzo -- npx -y @hanzo/mcp serve
claude mcp add --transport http hanzo-cloud https://api.hanzo.ai/v1/mcp \
  --header "Authorization: Bearer $HANZO_API_KEY"

# OpenAI Codex
codex mcp add hanzo -- npx -y @hanzo/mcp serve

# Cursor / Windsurf / VS Code / Gemini CLI / Antigravity MCP JSON
# {"mcpServers":{"hanzo":{"command":"npx","args":["-y","@hanzo/mcp","serve"]}}}
```

Load progressive skills on demand from [hanzoskills.com](https://hanzoskills.com) without bloating context:

```bash
curl -fsSL https://hanzoskills.com/CLAUDE.md >> ./CLAUDE.md
curl -fsSL https://hanzoskills.com/AGENTS.md >> ./AGENTS.md
```

## 3. Register Custom Remote MCP & ZAP Tool Servers

Mount your own internal microservices or high-throughput [ZAP](/docs/zap) binary endpoints into your organization's unified tool plane so every authorized agent inherits them automatically:

```bash
curl -X POST https://api.hanzo.ai/v1/tool/mcp/servers \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "internal-erp",
    "transport": "http",
    "url": "https://erp.internal.example.com/mcp"
  }'
```
