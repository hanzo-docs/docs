**Turn product releases into segmented, brand-consistent multi-channel launches measured by real conversion.**

## Architecture & contract

Zen drafts copy into CMS drafts via `POST /v1/content/generate`; Kai checks brand-safety rubrics; `/v1/marketing/audiences` defines exact recipient segments; `/v1/campaign` coordinates delivery and live metrics with instant `/pause`.

**Primary endpoint:** `POST /v1/campaign` · **Status:** `shipped` · **Level:** `practitioner`

## Run it across all four surfaces

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo marketing audiences create --data '{"name":"pro-developers","filter":{"tier":"pro"}}'
hanzo campaign create --data '{"name":"q4-release","objective":"adoption"}'
hanzo campaign summary
```
</Tab>
<Tab value="SDK">
<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">
```ts
import { Configuration, MarketingApi, CampaignApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [aud, camp] = await Promise.all([
  new MarketingApi(cfg).postMarketingAudiences({ name: 'pro-developers', filter: { tier: 'pro' } }),
  new CampaignApi(cfg).postCampaign({ name: 'q4-release', objective: 'adoption' }),
]);
console.log({ audience: aud.data, campaign: camp.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import MarketingApi, CampaignApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(MarketingApi(client).post_marketing_audiences({"name": "pro-developers", "filter": {"tier": "pro"}}))
print(CampaignApi(client).post_campaign({"name": "q4-release", "objective": "adoption"}))
```

```bash

  -H "Authorization: Bearer $HANZO_API_KEY" -H "Content-Type: application/json" \
```
