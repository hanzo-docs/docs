**Autonomy scales fastest when humans stay in the loop on irreversible actions.** Hanzo's durable review state lets an automation pause indefinitely without losing context until an authorized reviewer approves or rejects.

## Architecture & contract

When `permissions: "ask"` is set (or Kai confidence falls below threshold), the run checkpoints its state and emits a reviewable artifact. Submitting a review resumes or halts execution with full principal attribution.

**Primary endpoint:** `POST /v1/auto/automations/{id}/runs/{run}/review` · **Status:** `shipped` · **Level:** `practitioner`

import { Configuration, AutoApi } from 'hanzoai';

const auto = new AutoApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const runs = await auto.getAutoAutomationsByIdRuns(process.env.AUTO_ID!);
