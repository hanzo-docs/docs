**Autonomous agents without hard spend ceilings are an unbounded credit card.** Track per-agent burn on `GET /v1/agent/{ref}/spend` and wire threshold alerts on `/v1/billing/alerts`.

## Architecture & contract

Every inference and tool call made by an agent debits the same double-entry billing ledger while attributing cost to `agent_ref`, making runaway loops immediately visible and stoppable.

**Primary endpoint:** `GET /v1/agent/{ref}/spend` · **Status:** `shipped` · **Level:** `practitioner`

<Tab value="TypeScript">
```ts
import { Configuration, AgentApi, BillingApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [spend, balance, alerts] = await Promise.all([
  new AgentApi(cfg).getAgentByRefSpend('release-verifier'),
  new BillingApi(cfg).getBillingBalance(),
  new BillingApi(cfg).getBillingAlerts(),
]);
console.log({ spend: spend.data, balance: balance.data, alerts: alerts.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import AgentApi, BillingApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(AgentApi(client).get_agent_by_ref_spend("release-verifier"))
print(BillingApi(client).get_billing_balance())
print(BillingApi(client).get_billing_alerts())
```
