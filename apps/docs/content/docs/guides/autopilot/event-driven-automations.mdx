**Ditch fragile cron jobs and ad-hoc glue servers.** `/v1/auto/automations` executes event- and schedule-driven AI workflows with durable state, retry recovery, and full run history.

## Architecture & contract

Automations run strictly under the authenticated creator's permissions — another member's automations are never exposed. Durable state guarantees failed deliveries resume without creating duplicate runs.

**Primary endpoint:** `POST /v1/auto/automations` · **Status:** `shipped` · **Level:** `foundations`

import { Configuration, AutoApi } from 'hanzoai';
