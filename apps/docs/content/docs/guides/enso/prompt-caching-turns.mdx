**Unstructured dynamic prefixes invalidate prompt caches on every turn.** On a 100,000-token coding turn (`92k` cached, `6k` new, `2k` output), proper prefix caching cuts `enso-pro` turn cost from `\$0.363` to `\$0.0795` — a 4.6x savings.

## Architecture & contract

Place immutable system instructions, tool schemas, and repo summaries first, mark the boundary with `cache_control: {"type": "ephemeral"}`, and append volatile turn state (timestamps, diffs, user messages) strictly at the end.

**Primary endpoint:** `POST /v1/chat/completions` · **Status:** `shipped` · **Level:** `practitioner`

## Verify the outcome

- Run the same request twice with different user turns and verify `usage.prompt_tokens_details.cached_tokens > 0` on turn 2.

## Production guardrails

- Never inject `Date.now()` or random request IDs inside the cached prefix — even one changed byte busts the cache.
