**Compose exact model chains for compliance, budget, or latency-critical workloads.** `POST /v1/benchmark/presets` stores an org-scoped escalation blend resolved as `enso-<name>`.

## Architecture & contract

A blend specifies ordered `arms`, escalation rank, and `panel_width` (bounding parallel fan-out). Storing a preset registers the recipe without silently changing production traffic until you invoke it or promote it via an experiment.

**Primary endpoint:** `POST /v1/benchmark/presets` · **Status:** `shipped` · **Level:** `specialist`

<Tab value="TypeScript">
```ts
import { Configuration, BenchmarkApi } from 'hanzoai';

const bench = new BenchmarkApi(new Configuration({ accessToken: process.env.HANZO_API_KEY }));
const { data } = await bench.postBenchmarkPresets({
  name: 'sovereign-code',
  arms: ['zen6-flash', 'zen6-coder', 'zen6'],
  panel_width: 1,
});
console.log(data);
```

```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import BenchmarkApi

api = BenchmarkApi(ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"])))
print(api.post_benchmark_presets({
    "name": "sovereign-code",
    "arms": ["zen6-flash", "zen6-coder", "zen6"],
    "panel_width": 1,
}))
```
