**Turn every accepted diff, thumbs-up, or reverted patch into smarter routing.** `POST /v1/ai/feedback` teaches your org's bilinear routing utility which models win on your real workloads while storing zero prompt text.

## Architecture & contract

Each feedback event attaches a scalar reward (`accept`/`up` = `1.0`, `regenerate` = `0.25`, `down`/`switch`/`revert` = `0.0`) to `request_id`. Enso retrains candidate policies periodically and deploys a candidate strictly when it beats the incumbent on held-out reward.

**Primary endpoint:** `POST /v1/ai/feedback` · **Status:** `shipped` · **Level:** `specialist`

## Verify the outcome

- Emit both `accept` and `revert` signals in staging and verify HTTP `200` responses with recorded reward confirmation.

## Production guardrails

- Emit automatic objective signals (tests passed = `accept`, user switched model = `switch`) — explicit thumbs buttons alone skew toward outliers.
