Build low-latency hybrid Retrieval-Augmented Generation (RAG) and stateful applications on one unified `/v1` data plane — combining **`zen-embedding-2`** vectors, hybrid semantic + BM25 search (`/v1/index`, `/v1/search`), relational **Hanzo Base** (`/v1/base`, `/v1/provisioning/sql`), sub-millisecond **KV** (`/v1/kv`), and S3-compatible object storage (`/v1/s3`).

## 1. Provision Managed KV, Vector & SQL Stores

Provision dedicated data stores in your project namespace (and tear down ephemeral test stores cleanly inside `finally` / `defer`):

<Tabs items={['CLI', 'App', 'SDK', 'HTTP', 'MCP']}>

hanzo kv get rag-cache cursor:latest

## 2. Embed Documents & Run Hybrid Vector + BM25 Search

Combine `POST /v1/embeddings` (`zen-embedding-2`) with `/v1/index/indexes/{uid}/documents` and `/v1/index/indexes/{uid}/search` so exact identifiers (SKUs, error codes) and semantic concepts retrieve together:

```bash
# 1. Generate dense retrieval vectors with zen-embedding-2
curl -X POST https://api.hanzo.ai/v1/embeddings \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen-embedding-2",
    "dimensions": 768,
    "input": "title: Zero-Trust KMS | text: Rotate envelope keys per tenant namespace."
  }'

# 2. Index documents and query hybrid BM25 + semantic search
curl -X POST https://api.hanzo.ai/v1/index/indexes/kb/documents \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[{"id":"doc_1","title":"Zero-Trust KMS","body":"Rotate envelope keys per tenant namespace."}]'

curl -X POST https://api.hanzo.ai/v1/index/indexes/kb/search \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"q":"tenant envelope key rotation","limit":5}'
```

## 3. Join Realtime Base (`hanzoai/base`) & S3 Object Artifacts

Store raw PDFs, datasets, and model checkpoints in `/v1/s3` while keeping structured metadata and tenant ACLs in `/v1/base`:

```bash
# Create an S3 artifact bucket and list objects
curl -X POST https://api.hanzo.ai/v1/s3/buckets \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"rag-artifacts"}'

# Query tenant-scoped relational records via Hanzo Base GraphQL
curl -X POST https://api.hanzo.ai/v1/base/graphql \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"{ documents(limit: 5) { id title s3Key } }"}'
```
