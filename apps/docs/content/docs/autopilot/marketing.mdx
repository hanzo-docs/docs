**Agentic marketing separates creative drafting, audience governance, and empirical measurement.** Zen generates on-brand copy and campaign drafts; Kai checks compliance and brand-safety rubrics; `/v1/campaign` and `/v1/marketing` handle scheduling, delivery, and metrics; `/v1/experiment` proves which variant lifted conversion.

## End-to-end marketing autopilot pipeline

<Tab value="CLI">
```bash
# 1. Create and preview a segmented audience
hanzo marketing audiences create --data '{"name":"active-builders","filter":{"plan":"pro"}}'

# 2. Create a multi-channel campaign
hanzo campaign create --data '{"name":"zen6-launch","objective":"activation"}'

# 3. Inspect campaign performance metrics
hanzo campaign summary
```

import { Configuration, MarketingApi, CampaignApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const audience = await new MarketingApi(cfg).postMarketingAudiences({
  name: 'active-builders',
  filter: { plan: 'pro' },

  name: 'zen6-launch',
  objective: 'activation',
});

<Tab value="HTTP">
```bash
# 1. Generate brand-voice campaign copy into CMS as draft
curl -s -X POST https://api.hanzo.ai/v1/content/generate \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"zen6","brief":"Announce Kai CPU capability training to existing platform developers.","tone":"concise, technical, evidence-first"}' | jq '.'

# 2. Create & inspect campaign
CAMP_ID=$(curl -s -X POST https://api.hanzo.ai/v1/campaign \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"zen6-launch","objective":"activation"}' | jq -r '.id')

# 3. Read campaign metrics & pause immediately if anomaly detected
curl -s "https://api.hanzo.ai/v1/campaign/${CAMP_ID}/metrics" \
  -H "Authorization: Bearer $HANZO_API_KEY" | jq '.'
```

## Brand-safety & compliance gates

Before invoking `POST https://api.hanzo.ai/v1/campaign/{id}/launch` or `POST https://api.hanzo.ai/v1/marketing/broadcasts/{id}/send`:

1. Send every generated draft through `POST /v1/decisions` to verify zero unsubstantiated claims, prohibited phrases, or off-brand tone.
2. Send a test broadcast first via `POST https://api.hanzo.ai/v1/marketing/broadcasts/{id}/test`.
3. Attach subject assignment from `GET /v1/experiment/{id}/assign` so winning copy is promoted on measured click/conversion lift rather than opinions.
