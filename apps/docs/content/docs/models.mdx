Every model below is reachable with one key on one address. Pass the `id` as
`model` and the rest of the request is the same whichever you pick.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

The table is fetched from [`/v1/models`](/docs/openapi/ai) in your browser when
this page loads, so it is the catalogue the gateway is serving right now rather
than a copy written down when the page was built.

## What a rate means

Rates are per million tokens, input and output priced separately, and they are
the same whether you call from the CLI, an SDK, HTTP or an MCP tool — the price
is a property of the model, not of the surface you reach it through.

[Pricing](/docs/pricing) explains how usage becomes a bill. [Credits](/docs/credits)
covers what happens when the balance runs out.
