# Models

**After this page you know which model to ask for, and what to type to get it.**

Every model below answers on one endpoint — `https://api.hanzo.ai/v1` — with one
key. Choosing between them is choosing one string. There is no separate base URL
per provider, no second credential, and no client to swap.

<ProviderStrip />

## Two families are ours

Everything else in the catalogue is served on your behalf. Two families are
built here, and they are the ones to reach for first:

- **Enso** — Hanzo's frontier family, and the default for work that has to be
  right. Three tiers, one price/quality contract each: `enso-flash`, `enso`,
  `enso-ultra`. [What each is for →](/docs/enso)
- **Zen** — our **open-weight** models, from edge-sized to frontier. You can
  call them here, or download the weights and run them yourself; the ids below
  are the hosted ones. [On Hugging Face →](https://zenlm.org)

<Callout title="Not sure? Ask for `enso-flash`.">
It is the cheapest Enso tier and carries the full million-token context window.
Most work never needs to leave it, and moving up later is a one-word diff.
</Callout>

The first groups are the curated Hanzo families; everything after them is
grouped by the provider that trains the model. Every row is filterable, and the
model id copies with a click — that string is the whole integration.

## Passing an id

Whatever you copied goes in `model`. Nothing else about the request changes:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "enso-flash",
    "messages": [{ "role": "user", "content": "Name three uses for a paperclip." }]
  }'
```

`/v1/chat/completions` is a standard chat-completions endpoint, so an OpenAI
client you already have installed works against it once you point its base URL
at `https://api.hanzo.ai/v1`. Swapping `enso-flash` for `zen5-coder` — or for
any id in the table above — is the entire migration between models.

## Listing them yourself

The catalogue is public. No key, no account:

```bash
curl -s https://api.hanzo.ai/v1/models | jq '.summary'
```

Each entry in `.data[]` carries its `id`, `context`, `pricing` in USD per
million tokens, `features` and `provider`; `.families[]` names the curated
groups. That response is what this page renders, so the two cannot disagree —
and if you ever think they do, believe the endpoint.
