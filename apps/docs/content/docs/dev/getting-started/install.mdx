## System Requirements

| Requirement | Details |
| --- | --- |
| Operating systems | macOS 12+, Ubuntu 20.04+/Debian 10+, or Windows 11 **via WSL2** |
| Git (optional, recommended) | 2.23+ for built-in PR helpers |
| RAM | 4 GB minimum (8 GB recommended) |

## Install via npm

```bash
npm i -g hanzo
```

Any OS, Windows included. This installs the `hanzo` launcher only; `hanzo dev` downloads the native `dev` binary, SHA-256 verified, the first time it runs. `hanzo-dev` is the same agent under its own name.

## Run via npx

```bash
npx -y hanzo dev
```

## DotSlash

The GitHub Release also contains a [DotSlash](https://dotslash-cli.com/) file for Hanzo Dev named `dev`. Using a DotSlash file makes it possible to make a lightweight commit to source control to ensure all contributors use the same version of the executable, regardless of platform.

## Build from Source

```bash
# Clone the repository
git clone https://github.com/hanzoai/dev.git
cd dev

# Install the Rust toolchain if necessary
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# Initialize the engine submodule
git submodule update --init --depth 1

# Build (~20 min cold, ~2 min incremental)
make build

# Launch the TUI
./target/debug/dev
```

`make install` instead of `make build` puts an optimized `dev` on your PATH via
`cargo install`.

## Tracing / Verbose Logging

Hanzo Dev is written in Rust and honors the `RUST_LOG` environment variable.

The TUI defaults to `RUST_LOG=hanzo_core=info,hanzo_tui=info` and writes logs under `~/.hanzo/dev/log/`. Override the log directory with `-c log_dir=...` for a single run.

Non-interactive mode (`dev exec`) defaults to `RUST_LOG=error` with inline output.

See the Rust [`RUST_LOG` documentation](https://docs.rs/env_logger/latest/env_logger/#enabling-logging) for all configuration options.
