---
title: Error codes
description: Every error code Hanzo Index can return, with its HTTP status and type. The `link` in an error body points here.
---

Every error body carries a machine-readable `code`, a `type`, and a `link` back to this
page:

```json
{
  "message": "Index `nope` not found.",
  "code": "index_not_found",
  "type": "invalid_request",
  "link": "https://docs.hanzo.ai/docs/errors#index_not_found"
}
```

Match on `code`. It is stable; `message` is prose and may be reworded.
