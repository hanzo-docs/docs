**Every AI call has real marginal cost — pricing without live per-tenant metering destroys gross margin.** Hanzo's commerce, billing, pricing, and marketplace APIs share the exact same double-entry ledger the inference gateway debits on every request.

## Four monetization patterns

1. **Usage-based API & token billing**: Read real-time consumption from `GET /v1/billing/usage` and `GET /v1/billing/ledger`, set spend alerts on `/v1/billing/alerts`, and collect invoices via `/v1/billing/invoices`.
2. **Subscription + credit top-ups**: Define recurring tiers in `/v1/plan` backed by prepaid credit balances (`GET /v1/billing/credit-balance`).
3. **Marketplace distribution**: Package agents, MCP tools, or templates as verified listings on `POST /v1/marketplace/listings` with escrow-backed delivery on `/v1/marketplace/jobs`.
4. **Enterprise software licensing**: Mint signed license tokens (`POST /v1/licensing/issue`) for on-premise and air-gapped deployments verified via `POST /v1/licensing/verify`.

<Tab value="TypeScript">
```ts
import { Configuration, BillingApi, PricingApi, MarketplaceApi } from 'hanzoai';

const cfg = new Configuration({ accessToken: process.env.HANZO_API_KEY });
const [balance, pricing, listings] = await Promise.all([
  new BillingApi(cfg).getBillingBalance(),
  new PricingApi(cfg).getPricingModels(),
  new MarketplaceApi(cfg).getMarketplaceListings(),
]);
console.log({ balance: balance.data, pricing: pricing.data, listings: listings.data });
```
</Tab>
<Tab value="Python">
```python
import os
from hanzoai.cloud import ApiClient, Configuration
from hanzoai.cloud.api import BillingApi, PricingApi, MarketplaceApi

client = ApiClient(Configuration(access_token=os.environ["HANZO_API_KEY"]))
print(BillingApi(client).get_billing_balance())
print(PricingApi(client).get_pricing_models())
print(MarketplaceApi(client).get_marketplace_listings())
```

## Gross-margin engineering rule

Track `revenue_per_request` vs `model_cost_per_request` per customer org using `GET /v1/eval/metrics` and `GET /v1/billing/usage`. Move repetitive classification steps from generative models to Kai (`$0.021` per 1M input tokens, 0 output tokens) and enable Enso prompt caching (`cache_control`) to cut turn costs by up to 4.6x.
