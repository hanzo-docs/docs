Hanzo is not just for coding agents. It gives superpowers to any bot — coding assistants, research agents, workflow bots, Discord bots, Slack apps, custom agents you build yourself.

Two ways in:

1. **The toolset (MCP).** Add the `hanzo-mcp` server and your agent gets 13 unified tools (`fs`, `exec`, `code`, `git`, `fetch`, `workspace`, `ui`, `think`, `memory`, `hanzo`, `plan`, `tasks`, `mode`) plus every connector you've linked (GitHub, Slack, Google, Discord, X, and more) and your cloud services (IAM, Commerce, Storage, AI API). One connection, the whole surface.

2. **The model (OpenAI-compatible).** Point any OpenAI- or Anthropic-compatible client at `https://api.hanzo.ai/v1` with an `Authorization: Bearer $HANZO_API_KEY` header. Your model calls run on your Hanzo plan with proprietary model compression, personalization and fine-tuning.

Both work together or apart. A coding agent on your own plan can hand work to Enso and Kai through the tools. A research bot on Hanzo's models can still call the `hanzo` tool to reach your cloud.

## Get an API key

Every path needs a key. [Sign up free](https://hanzo.ai/signup) with a wallet — no card, no human — and mint a key at [console.hanzo.ai/api-keys](https://console.hanzo.ai/api-keys) or run:

```bash
curl -fsSL hanzo.sh | sh
hanzo login
hanzo account keys create --name my-agent --type secret
```

Set it as `HANZO_API_KEY` in your environment, or use the auth helpers each agent provides (they print the current token so no key is written to disk).

## The MCP server

The `hanzo-mcp` binary is the same everywhere. Install once:

```bash
# macOS / Linux
curl -fsSL hanzo.sh | sh
# Windows
npm install -g @hanzo/cli && hanzo upgrade
```

Then point your agent at the full path (`which hanzo-mcp` or `where hanzo-mcp`). The server uses your sign-in automatically, or pass `HANZO_API_KEY` explicitly.

## The model endpoint

- **Base URL:** `https://api.hanzo.ai/v1` (OpenAI-compatible)
- **Anthropic base:** `https://api.hanzo.ai`
- **Auth:** `Authorization: Bearer $HANZO_API_KEY`
- **Default model:** `enso-auto` (picks per request within your plan)
- **Model list:** `GET https://api.hanzo.ai/v1/models`

## What you get

- **Every model** — Enso (flash/pro/ultra), Zen (open-weights), and any model `GET /v1/models` returns
- **Kai decisions** — `kai_decide` tool for complex routing and planning
- **Search & retrieval** — Web, docs, workspace, and your connected data
- **Spend control** — Per-key budgets, per-session caps, rate limits, 402/429 with `resets_at` and `topup_url`
- **No human required** — Wallet sign-in, API top-up in USDC/USDT, all scriptable
