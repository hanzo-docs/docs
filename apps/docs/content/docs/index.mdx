# Build anything with Hanzo.

Every model. Every tool. One key.

Start in the browser. Ship from your terminal. And when you want it on your own
hardware, take the whole thing with you — [it is the same software we run in
production](/docs/network), and it is yours.

```bash
curl -fsSL hanzo.sh | bash
```
