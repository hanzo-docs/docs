## Take it with you

The cloud above and the one you can run yourself are [the same
software](/docs/network) — same binary, same contract, same `/v1` routes. Bring
your own GPU or Kubernetes, or mine on any device.

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
This is **V8 · Open Edition**, specified in [HIP-0127](https://hips.hanzo.ai):
one contract, many bindings, thin clients, and a wire — never FFI — between
languages. See [Engineering Philosophy](/docs/architecture/philosophy) for the *why*.
</Callout>

## Build with it

- [The `hanzo` CLI](/docs/openapi/platform) — one ~15 MB Rust binary that talks to any live cloud: prod, laptop, or self-host
- [SDKs](/docs/sdks) — Python, TypeScript, Go, Rust and more, all derived from one contract
- [API reference](/docs/openapi) — every endpoint, generated from its spec
- [ZAP protocol](/docs/zap) — Zero-Copy App Proto, the wire the Go and Rust halves speak
- [Zen models](https://zenlm.org) — frontier open-weight models, 4B edge to 1T+ reasoning
- [Architecture](/docs/architecture) — one binary, one contract, and why
