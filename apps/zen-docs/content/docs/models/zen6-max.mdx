# Zen6-Max
## Intelligence at enterprise scale.

**3.7 trillion parameters of aggregate expert capacity. One unified experience.**

Zen6-Max brings advanced reasoning, software engineering, research, and multimodal understanding together through one model interface. Designed for deployment on enterprise infrastructure, with performance tuned to the demands of each task.
