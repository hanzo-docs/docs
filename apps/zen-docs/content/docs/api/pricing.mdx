# Pricing

All pricing is **per 1 million tokens**. Every model's rate is published below and in the [console](https://console.hanzo.ai). Pay only for what you use.

## Pricing Methodology

Rates are set per model and cover serving, API management, and margin. Larger
and higher-tier models cost more per token because they cost more to run. The
rate for a model is the one shown in the table above and in the console — it
does not change per request, and there is no separate platform fee on top of
it.

## Billing

- **Prepaid**: Add credits via [console.hanzo.ai](https://console.hanzo.ai)
- **Minimum balance**: $1.00 required to make API calls
- **Usage tracking**: Real-time usage visible in console
- **No surprise bills**: Service stops when credits are depleted
