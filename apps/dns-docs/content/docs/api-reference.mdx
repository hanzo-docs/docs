Hanzo DNS exposes two API surfaces: the CoreDNS `hanzodns` REST API for direct DNS operations, and tRPC endpoints in the Hanzo Console for org-scoped management.

## CoreDNS REST API

The `hanzodns` plugin serves a REST API on port `:8443` (configurable).

### Authentication

Every route except `GET /v1/dns/health` requires a bearer token:

```
Authorization: Bearer <token>
```

The API picks exactly one auth boundary from configuration and fails closed:
`HANZO_DNS_OIDC_ISSUER` selects IAM-validated JWTs (multi-tenant production),
`HANZO_DNS_API_KEY` selects a static shared key (single-tenant standalone). With
neither set the API answers `503 unconfigured` — anonymous access exists only
behind an explicit `HANZO_DNS_DEV_INSECURE=1`.

### Endpoints

#### List Zones

```
GET /v1/dns/zones
```

Returns the caller's zones. Every operation is scoped to the org in the
validated `owner` claim — one org never sees another's zones.

**Response:**
```json
{
  "zones": [
    {
      "id": "z_01",
      "zone": "example.com.",
      "org": "acme",
      "provider": "authoritative",
      "status": "active",
      "nameservers": ["ns1.hanzo.ai.", "ns2.hanzo.ai."],
      "record_count": 3
    }
  ],
  "total": 1
}
```

#### Get Zone

```
GET /v1/dns/zones/{zone}
```

#### Create Zone

```
POST /v1/dns/zones
```

#### Delete Zone

```
DELETE /v1/dns/zones/{zone}
```

#### Get Zone Records

```
GET /v1/dns/zones/{zone}/records
```

**Response:**
```json
{
  "records": [
    {
      "id": "r_01",
      "name": "www",
      "type": "A",
      "content": "192.168.1.1",
      "ttl": 300,
      "proxied": false
    }
  ],
  "total": 1
}
```

#### Create Record

```
POST /v1/dns/zones/{zone}/records
```

**Request:**
```json
{
  "name": "www",
  "type": "A",
  "content": "192.168.1.1",
  "ttl": 300,
  "priority": 0
}
```

#### Get Record

```
GET /v1/dns/zones/{zone}/records/{id}
```

#### Update Record

```
PUT /v1/dns/zones/{zone}/records/{id}
PATCH /v1/dns/zones/{zone}/records/{id}
```

#### Delete Record

```
DELETE /v1/dns/zones/{zone}/records/{id}
```

#### Bulk Sync

```
POST /v1/dns/sync
```

Atomically replaces all records in one or more zones.

**Request:**
```json
{
  "zones": [
    {
      "zone": "example.com.",
      "records": [
        {"name": "www", "type": "A", "content": "192.168.1.1", "ttl": 300},
        {"name": "@", "type": "MX", "content": "mail.example.com.", "ttl": 3600, "priority": 10},
        {"name": "@", "type": "TXT", "content": "v=spf1 include:_spf.google.com ~all", "ttl": 3600}
      ]
    }
  ]
}
```

**Response:**
```json
{
  "synced": [
    {
      "zone": "example.com.",
      "record_count": 3,
      "created": 3,
      "deleted": 1
    }
  ],
  "total": 1
}
```

#### Health

```
GET /v1/dns/health
```

The one unauthenticated route. Returns `{"status":"ok"}`.

## Console tRPC API

The Console exposes org-scoped DNS management through tRPC procedures. All procedures use `protectedOrganizationProcedure` — the caller must be authenticated and have access to the organization.

### Zone Procedures

#### `dns.listZones`

List all zones for an organization.

```typescript
const zones = api.dns.listZones.useQuery({ orgId });
```

#### `dns.getZone`

Get a zone with its records.

```typescript
const zone = api.dns.getZone.useQuery({ orgId, id: zoneId });
```

#### `dns.createZone`

```typescript
api.dns.createZone.useMutation().mutate({
  orgId,
  name: 'example.com',
  cloudflareZoneId: 'optional-cf-zone-id',
});
```

#### `dns.deleteZone`

Cascade-deletes all records and audit logs.

```typescript
api.dns.deleteZone.useMutation().mutate({ orgId, id: zoneId });
```

### Record Procedures

#### `dns.listRecords`

```typescript
const records = api.dns.listRecords.useQuery({ orgId, zoneId });
```

#### `dns.createRecord`

```typescript
api.dns.createRecord.useMutation().mutate({
  orgId,
  zoneId,
  name: 'www',
  type: 'A',
  content: '192.168.1.1',
  ttl: 300,
  syncToCloudflare: false,
});
```

#### `dns.updateRecord`

```typescript
api.dns.updateRecord.useMutation().mutate({
  orgId,
  id: recordId,
  content: '10.0.0.1',
  ttl: 600,
});
```

#### `dns.deleteRecord`

```typescript
api.dns.deleteRecord.useMutation().mutate({ orgId, id: recordId });
```

### Audit Log Procedures

#### `dns.listAuditLogs`

Cursor-based pagination.

```typescript
const logs = api.dns.listAuditLogs.useQuery({
  orgId,
  zoneId,
  cursor: undefined, // for first page
  limit: 50,
});
```
