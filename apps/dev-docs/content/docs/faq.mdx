## Which models are supported?

By default, Hanzo Dev uses `enso-auto` (the learned router that picks the optimal model for each turn) and supports the full Zen family (`zen5`, `zen5-pro`, `zen5-max`, `zen5-ultra`, `zen5-mini`) as well as all frontier models served on `https://api.hanzo.ai/v1`. Switch models anytime with `/model <name>` or `--model`, and toggle priority speed with `/fast`.

## How do I stop Hanzo Dev from editing my files?

By default, Hanzo Dev can modify files in your current working directory (Auto mode). To prevent edits, run in read-only mode:

```bash
dev --sandbox read-only
```

Or change the approval level mid-conversation with `/approvals`.

## Does it work on Windows?

Yes — install globally with `npm i -g hanzo` and run `hanzo dev`, or use [Windows Subsystem for Linux (WSL2)](https://learn.microsoft.com/en-us/windows/wsl/install).

## Why can't Hanzo Dev find my agents on Windows?

Agent discovery on Windows can be affected by PATH and file extensions. Solutions:

### Use absolute paths (recommended)

```toml
[[agents]]
name = "claude"
command = "C:\\Users\\YourUser\\AppData\\Roaming\\npm\\claude.cmd"
enabled = true
```

### Find your npm global install location

```bash
npm config get prefix
```

### Verify PATH includes npm directory

```powershell
$env:PATH -split ';' | Select-String "npm"
```

### Check file extensions

On Windows, Hanzo Dev looks for executables with extensions: `.exe`, `.cmd`, `.bat`, `.com`. Include the correct extension when using absolute paths.
